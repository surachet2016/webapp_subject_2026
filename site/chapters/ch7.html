บทนำ

ภาษาพีเอชพี (PHP: Hypertext Preprocessor) เป็นภาษาคอมพิวเตอร์สำหรับการพัฒนาเว็บแอปพลิเคชันฝั่งเซิร์ฟเวอร์ (Server-Side Scripting) ที่ได้รับความนิยมและมีการใช้งานอย่างแพร่หลายที่สุดในโลก ทำหน้าที่ประมวลผลตรรกะทางธุรกิจ การคำนวณ การติดต่อสื่อสารกับฐานข้อมูล ตลอดจนการสร้างเนื้อหาเว็บเพจแบบไดนามิก (Dynamic Web Pages) ก่อนที่จะส่งผลลัพธ์กลับไป แสดงผลบนเว็บเบราว์เซอร์ของผู้ใช้งานในรูปแบบ HTML ในปัจจุบันภาษา PHP ได้รับการพัฒนาจนถึงเวอร์ชัน PHP 8.x ซึ่งมาพร้อมกับ การเพิ่มประสิทธิภาพความเร็วระดับสูง (JIT Compiler) การกำหนดชนิดข้อมูลอย่างเข้มงวด (Strict Typing) และความมั่นคงปลอดภัย ในบทนี้นักศึกษาจะได้ศึกษาตั้งแต่การจำลองสภาพแวดล้อมเว็บเซิร์ฟเวอร์ด้วย XAMPP, ไวยากรณ์พื้นฐาน, โครงสร้างควบคุม, การสร้างฟังก์ชัน, การรับส่งข้อมูลผ่านฟอร์มและเซสชัน, มาตรฐานความปลอดภัย ตลอดจนการประยุกต์ใช้ปัญญาประดิษฐ์ (AI) ในการช่วยเขียนและตรวจสอบโค้ดหลังบ้านอย่างมีประสิทธิภาพ

เนื้อหา

ก่อนเริ่มเขียนโปรแกรมภาษา PHP จำเป็นต้องติดตั้งโปรแกรม XAMPP เพื่อจำลองให้เครื่องคอมพิวเตอร์ทำหน้าที่เป็นเว็บเซิร์ฟเวอร์ (Web Server) สำหรับพัฒนาเว็บไซต์ด้วย WordPress, Joomla หรือ PHP โดยแนะนำให้ใช้ XAMPP เนื่องจากเป็นโปรแกรมที่มีการปรับปรุงอย่างต่อเนื่องและเป็นที่นิยมในการพัฒนา หรืออาจติดตั้ง AppServ แทนก็ได้

โดย XAMPP นั้นจะมาพร้อมกับ Apache และ MySQL (phpmyadmin)

หมายเหตุสำหรับผู้ใช้ macOS: ตามหน้าดาวน์โหลดของ Apache Friends (ตรวจเมื่อ 8 พฤศจิกายน 2569) XAMPP มีรุ่นสำหรับ Windows เท่านั้น ผู้ใช้ macOS ใช้ MAMP หรือเซิร์ฟเวอร์ที่มากับ PHP เอง (php -S) แทน ดูรายละเอียดและวิธีแก้ปัญหาพอร์ตซ้ำกันในภาคผนวก ค

7.2 การเขียนคำอธิบายในภาษา PHP

ถ้าเราต้องการเขียนคำอธิบายในส่วนใดๆก็ตามของสคริปต์ เราก็จะสามารถทำได้โดยใช้ /* ... */ เหมือนในภาษาซี หรือ // เหมือนในภาษาจาวา หรือ # เหมือน shell script โปรดสังเกตว่า // ใช้เขียนนำคำอธิบายในภายบรรทัดหนึ่งๆ เท่านั้น ส่วน # ใช้เริ่มต้นของบรรทัดที่เขียนคำอธิบาย

ตัวอย่างการเขียนโปรแกรม

โค้ด
<?php
 # comment 
$a = 41; // set $a to 41. 
$b =10; // set $b to 10. 
$b += $a; /* add $a to $b */ 
echo $b," "; 
?>

แสดงผลลัพธ์

7.3 คำสั่งแสดงข้อความ echo

การพิมพ์ค่าใดๆที่เก็บอยู่ในตัวแปร ถ้าชื่อของตัวแปรอยู่ในสตริงค์ระหว่าง double quote เวลาสร้างเอาพุตแล้ว จะอ่านค่าของตัวแปรนั้นก่อนแล้วจึงแทนที่ลงในข้อความ แต่ถ้านำหน้าด้วย backslash () ก็จะไม่มีการอ่านค่าของตัวแปร เช่น "$a" จะให้ผลต่างจาก "$a" สังเกตได้จากตัวอย่างต่อไปนี้

โค้ด
<?php
 $a=1;
 echo "$a=$a <BR> ";
 $test = "test"; 
 echo "$test$test$test<BR> "; 
 echo $test,$test,$test,"<BR> ";
 $a = 1; 
 $b = 2; 
 echo $a,"+",$b,"=","$a+$b","<BR> "; 
 echo $a,"+",$b,"=",$a+$b,"<BR> "; 
 ?>

แสดงผลลัพธ์

7.4 การสอดแทรกคำสั่งภาษา PHP ใน HTML

เพื่อเป็นการบ่งบอกให้รู้ว่า ส่วนใดเป็นคำสั่ง ที่อยู่ภายในเอกสาร จึงได้มีการกำหนดสัญลักษณ์ไว้ดังนี้ ซึ่งสามารถทำได้หลายรูปแบบ เช่น

โค้ด
<? ... ?> (SGML style)
<?php ... ?>? (XML style)
<script language="php"> ... </script> (JavaScript style)
  • <% ... %> (ASP style)

ที่นิยมก็คือแบบแรก โดยเริ่มต้นด้วย <? และจบด้วย ?> และตรงกลางจะเป็นคำสั่งในภาษา PHP

เราสามารถวางคำสั่ง ไว้ภายในเอกสาร ตามที่ต้องการได้ อาจจะสลับกับ Tag ของภาษา ก็ได้ ตัวอย่างเช่น

โค้ด
<HTML>
<HEAD>
<TITLE> My Homepage </TITLE>
</HEAD>
<BODY BGCOLOR=#FFFFFF>
<H1><?php echo "Hello World"; ?></H1> 
Your web browser is 
<?php echo $_SERVER['HTTP_USER_AGENT']; ?>.
</BODY>
</HTML>

7.5 การใช้ตัวแปรในภาษา PHP

สำหรับการเขียนโปรแกรมสำหรับภาษาคอมพิวเตอร์ระดับสูง สิ่งที่จะขาดเสียมิได้คือ การกำหนดและใช้ตัวแปร (variable) ตัวแปรในภาษา จะเหมือนกับในภาษา Perl คือเริ่มต้นด้วยเครื่องหมาย dollar ($) โดยเราไม่จำเป็นต้องกำหนดแบบของข้อมูล () อย่างเจาะจงเหมือนในภาษาซี เพราะว่า ตัวแปลภาษาจะจำแนกเองโดยอัตโนมัติว่า ตัวแปรดังกล่าว ใช้ข้อมูลแบบใด ในช่วงเวลานั้นๆ เช่น ข้อความ จำนวนเต็ม จำนวนที่มีเลขจุดทศนิยมตรรก เป็นต้น

ตัวอย่างการเขียนโปรแกรม

โค้ด
<?php
$mystring = "Hello World!";
$myinteger = 1031;
$myfloat = 3.14;
echo "$mystring"; 
echo '<br/>';
echo "$myinteger"; 
echo '<br/>';
echo "$myfloat";

?>

แสดงผลลัพธ์

ตัวแปรตัวหนึ่ง อาจจะมีข้อมูลหลายแบบในช่วงเวลาที่ต่างกัน แต่การจะใช้งานบ้างครั้งจะต้องดูด้วยว่า เมื่อไหร่จะใช้เป็นตัวเลขเท่านั้น และไม่ใช้กับข้อความเป็นต้น ตัวอย่างเช่น

โค้ด
<?php
$x = 10; 
$y = $x + 15.5; 
echo "$x, $y "; 
echo '<br>';
$x = "abc"; 
echo "$x "; 
echo '<br>';
$z = $x + 15.5; 
echo "$x, $z "; 
echo '<br>'; 
echo ("100.5" - 16); 
echo '<br>';
echo (0xef + 007);

?>

7.6 แนะนำคำสั่ง IF ในภาษา PHP

คำสั่ง IF ในภาษา PHP คือคำสั่งเงื่อนไขที่ใช้ในการตรวจสอบเงื่อนไขว่าเป็นจริงหรือเท็จ โดยใช้คำสั่ง if จะช่วยให้โปรแกรมทำงานตามเงื่อนไขที่กำหนดไว้ โดยในกรณีที่เป็นจริง โปรแกรมจะทำงานตามคำสั่งที่กำหนดไว้ในบล็อกที่อยู่ในเครื่องหมายปีกกา {} ซึ่งถ้าเงื่อนไขเป็นเท็จ โปรแกรมจะไม่ทำงานในบล็อกเงื่อนไขนั้น และทำงานต่อไปนอกจากนี้ ยังสามารถเพิ่มเงื่อนไขเข้าไปเพิ่มเติมโดยใช้คำสั่ง else เพื่อกำหนดคำสั่งที่ต้องการให้ไม่เป็นจริง แต่เราสามารถลดความยาวของคำสั่งและการทำงานลงได้ โดยการใช้ "IF แบบสั้น"

รูปแบบการเขียนคำสั่ง IF

if (เงื่อนไข) {
// คำสั่งที่จะถูกดำเนินการถ้าเงื่อนไขเป็นจริง
} else {
// คำสั่งที่จะถูกดำเนินการถ้าเงื่อนไขไม่เป็นจริง
}

แต่เราสามารถลดความยาวของคำสั่งและการทำงานลงได้ โดยการใช้ IF แบบสั้น

If แบบสั้นหรือ "Ternary operator" คือ การเขียนคำสั่ง if ในรูปแบบที่สั้นกว่าโดยใช้เครื่องหมาย ? เพื่อแทนการเขียนเงื่อนไข if แบบธรรมดา โดยมักนิยมใช้งานในการกำหนดค่าตัวแปรแบบเงื่อนไขเดียว ดังนั้นคำสั่ง if แบบย่อจึงเป็นวิธีการเขียน if ที่สั้นและกระชับขึ้น

รูปแบบของ if แบบย่อคือ: (เงื่อนไข) ? (คำสั่งถูกเลือกเมื่อเงื่อนไขเป็นจริง) : (คำสั่งถูกเลือกเมื่อเงื่อนไขเป็นเท็จ)

ตัวอย่างการเขียนโปรแกรม

โค้ด
<?php 
$text = 2; 
if($text == 1){ 
  echo "True"; 
}else{ 
echo "False"; 
}

?>

แสดงผลลัพธ์

ถ้าต้องการเขียนแบบสั้นจะได้ดังนี้

โค้ด
<?php 
$text = 2; 
echo ($text == 1 ? "True" : "False");

?>

แสดงผลลัพธ์

7.7 แนะนำ คำสั่ง If Else-If

คำสั่ง If-Else ใช้สร้างเงื่อนไขแบบสองทางเลือก คือจริงหรือไม่จริงเท่านั้น ในภาษา PHP สามารถสร้างเงื่อนไขแบบหลายทางเลือกได้โดยใช้คำสั่ง Else-If สำหรับเงื่อนไขเพิ่มเติมที่ต้องการ โดยยกตัวอย่างการใช้กับโปรแกรมคำนวณเกรด

โค้ด
<?php

$score = 79;

if ($score >= 80) {
    echo "Your grade is A.";    
} else if ($score >= 70) {
    echo "Your grade is B.";    
} else if ($score >= 60) {
    echo "Your grade is C.";    
} else if ($score >= 50) {
    echo "Your grade is D.";    
} else {
    echo "Sorry, you got grade F."; 
}

?>
แสดงผลลัพธ์

7.8 แนะนำคำสั่ง Switch case ในภาษา PHP

คำสั่งการใช้เงื่อนไขแบบ switch case เป็นภาษาแบบทางเลือกหลายทาง โดยที่มีทางเลือกให้ทำแบบหลายทางเลือก แต่ให้ทำแค่ทางเลือกเดียวเท่านั้น ซึ่งคำสั่งเลือกเงือนไขการทำงานของคำสั่งนี้จะคล้ายกับคำสั่ง If Else-If ซึ่งเป็นการเลือกแบบหลายทางเลือก แต่ในคำสั่ง Switch จะใช้สำหรับเปรียบเทียบกับค่าคงที่โดยตรงที่ไม่ใช่ Expression

ตัวอย่างการเขียนโปรแกรม

โค้ด
 <?php

$abb = "th";

switch ($abb) {
    case "de":
        $country = "Germany";
        break;
    case "th":
        $country = "Thailand";
        break;
    case "hu":
        $country = "Hungary";
        break;
    case "tr":
        $country = "Turkey";
        break;

ฟังก์ชัน date()

เป็น Functions ที่ใช้ในการจัดรูปแบบ วันที่ และเวลา

ซึงในบทความนี้ จะแนะนำเกร็ดความเบื้องต้นเล็กๆน้อยๆ เกี่ยวกับวันที่และเวลาในภาษา ซึ่งจะพูดถึงถึงเกี่ยวกับการแสดงวันที่ และเวลาใน

iนาที
sวินาที

a am หรือ pm

7.11 การจัดการข้อมูลฟอร์มและเซสชัน (Form Processing & Session Management) (ชาญชัย ศุภอรรถกร, 2564)

หัวใจสำคัญของการทำงานฝั่งเซิร์ฟเวอร์คือการรับข้อมูลจากผู้ใช้งานผ่านแบบฟอร์ม HTML และการจดจำสถานะของผู้ใช้งาน (State Management) ผ่านตัวแปรซูเปอร์โกลบอล (Superglobals) ของ PHP ดังนี้:

7.11.1 การรับค่าข้อมูลผ่านตัวแปร $_GET และ $_POST

• $_GET: รับข้อมูลที่ส่งมาพร้อมกับ URL เหมาะสำหรับการค้นหาข้อมูล การแบ่งหน้า (Pagination) ไม่เหมาะสำหรับข้อมูลความลับเนื่องจากข้อมูลจะปรากฏบนแถบที่อยู่ของเบราว์เซอร์
• $_POST: รับข้อมูลที่ส่งผ่าน HTTP Request Body เหมาะสำหรับการส่งข้อมูลแบบฟอร์ม เช่น การลงทะเบียน การเข้าสู่ระบบ หรือการส่งข้อมูลที่มีความยาวมาก

ตัวอย่างการรับค่าและป้องกัน XSS ด้วย htmlspecialchars():
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
$username = htmlspecialchars(trim($_POST['username']));
echo "ยินดีต้อนรับคุณ " . $username;
}

7.11.2 การจัดการเซสชัน (Session) สำหรับระบบสมาชิก

เนื่องจากโพรโทคอล HTTP มีลักษณะเป็น Stateless (ไม่จดจำสถานะการติดต่อ) PHP จึงมีระบบเซสชันเพื่อเก็บข้อมูลของผู้ใช้งานไว้บนเซิร์ฟเวอร์ตลอดการเข้าชม:
session_start(); // ต้องเรียกใช้เป็นคำสั่งแรกก่อนมีผลลัพธ์ HTML
$_SESSION['user_id'] = 101;
$_SESSION['role'] = 'admin';

เมื่อต้องการออกจากระบบ จะใช้คำสั่ง session_unset() และ session_destroy() เพื่อล้างข้อมูลเซสชันอย่างปลอดภัย

7.11.3 ตัวอย่างระบบเข้าสู่ระบบด้วย Session (login.php, dashboard.php, logout.php)

ระบบเข้าสู่ระบบอย่างง่ายแบ่งเป็น 3 ไฟล์ในโฟลเดอร์เดียวกัน คือ login.php ตรวจชื่อผู้ใช้และรหัสผ่านแล้วเก็บสถานะใน $_SESSION, dashboard.php ตรวจว่าล็อกอินแล้วจึงแสดงเนื้อหา และ logout.php ล้างเซสชัน ตัวอย่างนี้เก็บผู้ใช้ไว้ในอาร์เรย์เพื่อการเรียนเท่านั้น (รหัสผ่านทดลองคือ Secret1234 ผู้ใช้ admin) ในงานจริงต้องเก็บผู้ใช้และค่าแฮชในฐานข้อมูล ตามบทที่ 8

ไฟล์ login.php

โค้ด
<?php
session_start();
// ตัวอย่างเพื่อการเรียน: ในงานจริงให้ดึงผู้ใช้และค่าแฮชจากฐานข้อมูล (บทที่ 8)
$users = ['admin' => password_hash('Secret1234', PASSWORD_DEFAULT)];
$error = '';
if ($_SERVER['REQUEST_METHOD'] === 'POST') {
    $user = trim($_POST['username'] ?? '');
    $pass = $_POST['password'] ?? '';
    if (isset($users[$user]) && password_verify($pass, $users[$user])) {
        session_regenerate_id(true);
        $_SESSION['user'] = $user;
        header('Location: dashboard.php');
        exit;
    }
    $error = 'ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง';
}

?>

return $price * $quantity;
}
2. นิพจน์ Match (Match Expression): รูปแบบใหม่ที่กระชับและปลอดภัยกว่า switch case เพราะมีการเปรียบเทียบแบบ Strict (===) และคืนค่าได้ทันที:
$message = match($statusCode) {
200 => 'สำเร็จ',
404 => 'ไม่พบข้อมูล',
default => 'เกิดข้อผิดพลาด'
};
3. Nullsafe Operator (?->): ช่วยเรียกใช้ออบเจกต์หรือเมธอดโดยไม่ต้องเขียน if ตรวจสอบ null ซ้ำซ้อน

7.12.2 การเข้ารหัสรหัสผ่านที่ปลอดภัย (Secure Password Hashing)

การเก็บรหัสผ่านของผู้ใช้งาน ห้ามเก็บเป็นข้อความธรรมดา (Plain Text) หรือฟังก์ชันแฮชยุคเก่าที่ถูกเจาะได้แล้ว เช่น md5() หรือ sha1() โดยเด็ดขาด PHP แนะนำให้ใช้ฟังก์ชันมาตรฐานระดับสากล ได้แก่:
• การแฮชรหัสผ่าน: $hash = password_hash($password, PASSWORD_DEFAULT); // ใช้อัลกอริทึม Bcrypt ร่วมกับ Salt อัตโนมัติ
• การตรวจสอบรหัสผ่านเมื่อเข้าสู่ระบบ: if (password_verify($password, $hash)) { /* ผ่าน */ }

7.12.3 การป้องกันเซสชันและการอัปโหลดไฟล์อย่างปลอดภัย (Session & Upload Security)

• การป้องกัน Session Hijacking & Fixation: เรียกใช้ session_regenerate_id(true) ทันทีที่มีการเปลี่ยนสถานะการล็อกอิน และตั้งค่า Cookie ให้มีแฟล็ก HttpOnly, Secure, และ SameSite=Strict

• การอัปโหลดไฟล์ที่ปลอดภัย: ห้ามตรวจสอบนามสกุลไฟล์เพียงอย่างเดียว ต้องใช้ finfo_file() เพื่อตรวจสอบค่า MIME Type ที่แท้จริง และเปลี่ยนชื่อไฟล์เป็น UUID หรือรหัสแฮชสุ่ม พร้อมจัดเก็บในโฟลเดอร์ที่ปิดการทำงานของ PHP Script (OWASP, 2023d)

7.13 เทคนิคการใช้ AI ช่วยเขียนและตรวจสอบโค้ด PHP (AI-Assisted PHP Development) (Open Web Application Security Project [OWASP], 2023d; The PHP Group, 2024b)

การพัฒนาโปรแกรมฝั่งเซิร์ฟเวอร์มีความสำคัญอย่างยิ่งต่อความมั่นคงปลอดภัยของระบบ ผู้ช่วย AI (เช่น GitHub Copilot, Cursor, ChatGPT) สามารถเข้ามาช่วยเร่งความเร็วในการสร้างฟังก์ชันตรรกะ พร้อมทั้งเป็นผู้ช่วยตรวจทานช่องโหว่ความปลอดภัย (Security Audit)

7.13.1 การสั่งงาน AI สร้างฟังก์ชันประมวลผลหลังบ้าน

นักพัฒนาสามารถใช้ Prompt เพื่อให้ AI ร่างฟังก์ชันที่รองรับการจัดการข้อผิดพลาด (Error Handling) ได้อย่างรัดกุม เช่น:
Prompt: "ช่วยเขียนฟังก์ชัน PHP 8 สำหรับคำนวณภาษีมูลค่าเพิ่ม 7% และส่วนลดตามระดับสมาชิก (Silver 5%, Gold 10%) โดยมีการระบุ Type Hinting ชัดเจน และมีฟังก์ชันตรวจสอบว่ายอดเงินต้องไม่ติดลบ หากติดลบให้ Throw Exception ออกมา"
AI จะสร้างฟังก์ชันที่มีโครงสร้าง Clean Code พร้อม Try-Catch Block ได้อย่างสมบูรณ์

7.13.2 การให้ AI ตรวจสอบช่องโหว่และความปลอดภัย (Security Code Review)

• การตรวจสอบคำสั่งล้าสมัย (Deprecated Code): ให้ AI ช่วยสแกนโค้ดและแจ้งเตือนฟังก์ชันเก่าที่ไม่รองรับใน PHP 8
• การตรวจสอบการทำ Sanitization: ให้ AI ค้นหาจุดที่มีการนำค่าจาก $_GET หรือ $_POST ไปแสดงผลโดยตรงโดยไม่ได้ผ่าน htmlspecialchars()
• ข้อควรระวัง: โค้ดตัวอย่างที่ AI แนะนำบางครั้งอาจยังคงใช้วิธีต่อสตริงในคำสั่ง SQL (SQL Concatenation) นักพัฒนาต้องเปลี่ยนมาใช้ Prepared Statements (ซึ่งจะศึกษาอย่างละเอียดในบทที่ 8) เสมอ

7.13.3 กรอบคำสั่ง AI สำหรับการตรวจสอบความปลอดภัยของโค้ดหลังบ้าน (Prompt for PHP Security Audit)

"Role: Senior Backend Security Auditor. / Task: Audit this PHP 8 login processing script. Check for Session Fixation, CSRF vulnerability, and improper password verification. / Constraints: Enforce declare(strict_types=1);, session_regenerate_id(true), password_verify(), and secure session cookie parameters."

7.13.4 ตัวอย่างโค้ดระบบประมวลผลการเข้าสู่ระบบที่ปลอดภัยตามมาตรฐาน PHP 8.x

<?php
declare(strict_types=1);

// ตั้งค่าความปลอดภัยของเซสชันก่อนเริ่มต้น
session_set_cookie_params([
'lifetime' => 3600,
'path' => '/',
'domain' => '',
'secure' => true, // ส่งผ่าน HTTPS เท่านั้น
'httponly' => true, // ป้องกัน JavaScript เข้าถึง Cookie (กัน XSS ขโมย Session)
'samesite' => 'Strict' // ป้องกันการโจมตีแบบ CSRF
]);
session_start();

function processUserLogin(string $inputUsername, string $inputPassword, array $userFromDatabase): bool {
// ตรวจสอบว่าพบบัญชีผู้ใช้ในระบบหรือไม่
if (!$userFromDatabase) {
return false;
}

// ตรวจสอบรหัสผ่านที่ส่งมา เทียบกับแฮชในฐานข้อมูล (Bcrypt/Argon2id)
if (password_verify($inputPassword, $userFromDatabase['password_hash'])) {
// ป้องกัน Session Fixation ด้วยการสร้าง Session ID ใหม่ทันที
session_regenerate_id(true);

$_SESSION['authenticated'] = true;
$_SESSION['user_id'] = $userFromDatabase['id'];
$_SESSION['username'] = $userFromDatabase['username'];
$_SESSION['login_time'] = time();
return true;
}
return false;
}
?>

สรุป

ภาษา PHP เป็นภาษาประมวลผลฝั่งเซิร์ฟเวอร์ (Server-Side Scripting) ที่เป็นกำลังสำคัญในการขับเคลื่อนเว็บแอปพลิเคชันทั่วโลก โดยสามารถทำงานร่วมกับเว็บเซิร์ฟเวอร์ Apache ผ่านโปรแกรมจำลอง เช่น XAMPP โครงสร้างภาษาประกอบด้วยการประกาศตัวแปร ($) ชนิดข้อมูลคำสั่งควบคุมเงื่อนไข (if, else-if, switch case) และคำสั่งวนรอบ (while, for, foreach) ตลอดจนการสร้างฟังก์ชันเพื่อนำโค้ดกลับมาใช้ซ้ำ การพัฒนาในยุคปัจจุบันได้ยกระดับสู่มาตรฐาน PHP 8.x ที่รองรับการระบุชนิดข้อมูล (Type Declarations) และ Match Expression รวมถึงการจัดการข้อมูลฟอร์มอย่างปลอดภัยผ่าน $_GET / $_POST, การจดจำสถานะผู้ใช้ด้วย $_SESSION, และการรักษาความปลอดภัยของรหัสผ่านด้วย password_hash() การผสานการทำงานร่วมกับผู้ช่วย AI จะช่วยให้นักพัฒนาสามารถวิเคราะห์ตรรกะ ค้นหาข้อผิดพลาด และป้องกันช่องโหว่ความปลอดภัย เพื่อเตรียมความพร้อมสู่การเชื่อมต่อกับระบบฐานข้อมูลในระดับมืออาชีพต่อไป

แบบฝึกหัด

คำชี้แจง: จงทำแบบฝึกหัดต่อไปนี้เพื่อทบทวนความรู้ความเข้าใจ

ตอนที่ 1: แบบฝึกหัดเชิงทฤษฎีและการวิเคราะห์ (Theoretical & Analytical Exercises)

1. จงอธิบายวงจรการทำงาน (Lifecycle) ของภาษา PHP เมื่อผู้ใช้งานร้องขอ (Request) หน้าเว็บเพจผ่านเว็บเบราว์เซอร์จนกระทั่งได้รับผลลัพธ์ (Response) กลับมา

2. จงเปรียบเทียบความแตกต่างระหว่างการส่งข้อมูลผ่านฟอร์มด้วยวิธี GET (ผ่าน $_GET) และวิธี POST (ผ่าน $_POST) ในภาษา PHP ทั้งในด้านความปลอดภัย ปริมาณข้อมูล และลักษณะการใช้งานที่เหมาะสม

3. ระบบเซสชัน ($_SESSION) มีความสำคัญอย่างไรต่อการพัฒนาเว็บแอปพลิเคชันที่มีระบบเข้าสู่ระบบ (Login System) และมีความแตกต่างจากคุกกี้ ($_COOKIE) อย่างไร

4. จงอธิบายข้อดีของการระบุชนิดข้อมูล (Type Declarations) และการใช้นิพจน์ Match (Match Expression) ในภาษา PHP 8.x เมื่อเปรียบเทียบกับคำสั่งแบบเดิมในเวอร์ชันก่อนหน้า

5. เหตุใดการเข้ารหัสรหัสผ่านของผู้ใช้งานจึงไม่ควรใช้ฟังก์ชัน md5() หรือ sha1() และฟังก์ชัน password_hash() ร่วมกับ password_verify() ใน PHP มีกลไกการรักษาความปลอดภัยอย่างไร

6. ปัญญาประดิษฐ์ (AI Coding Assistants) สามารถช่วยเหลือนักพัฒนาในการเขียนโค้ดและตรวจสอบความมั่นคงปลอดภัย (Security Audit) ของโปรแกรมภาษา PHP ได้อย่างไรบ้าง จงยกตัวอย่างข้อควรระวัง
