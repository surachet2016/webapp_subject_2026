บทนำ

ภาษา HTML (HyperText Markup Language) เป็นรากฐานสำคัญสูงสุดของการสร้างและพัฒนาเว็บเพจบนระบบอินเทอร์เน็ต โดยทำหน้าที่เป็นโครงสร้างหลัก (Structure & Skeleton) ในการจัดวางเนื้อหา ข้อความ รูปภาพ ตาราง แบบฟอร์มรับข้อมูล และสื่อประสมต่าง ๆ ปัจจุบันมาตรฐานได้พัฒนาสู่เวอร์ชัน HTML5 ซึ่งได้เพิ่มคุณสมบัติแท็กเชิงความหมาย (Semantic Tags) การรองรับสื่อมัลติมีเดียโดยไม่ต้องพึ่งพาปลั๊กอินภายนอก ตลอดจนการสนับสนุนการเข้าถึงข้อมูล (Web Accessibility) และการเพิ่มประสิทธิภาพสำหรับการค้นหา (SEO) ในบทนี้นักศึกษาจะได้เรียนรู้โครงสร้างมาตรฐาน ไวยากรณ์แท็กเดี่ยวและแท็กคู่ การจัดการแบบฟอร์ม ตลอดจนการประยุกต์ใช้เครื่องมือและผู้ช่วยอัจฉริยะ (AI) ในการเขียนโค้ด HTML5 อย่างมีประสิทธิภาพ

3.1 การจัดเตรียมโปรแกรมแก้ไขโค้ด (Visual Studio Code) และส่วนขยายอำนวยความสะดวก

Visual Studio Code (VS Code) เป็นโปรแกรมแก้ไขโค้ดฟรีของ Microsoft ใช้ได้ทั้ง Windows, macOS และ Linux มีส่วนขยายให้เลือกมาก จึงใช้เป็นเครื่องมือหลักในรายวิชานี้

ขั้นตอนการติดตั้งและตั้งค่า

1. ดาวน์โหลดตัวติดตั้งจากเว็บไซต์ https://code.visualstudio.com/ แล้วติดตั้งตามค่าเริ่มต้น (Windows ให้เลือก Add to PATH ส่วน macOS ให้ลากโปรแกรมไปไว้ในโฟลเดอร์ Applications)

2. เปิดหน้าต่าง Extensions ด้วย Ctrl+Shift+X (macOS ใช้ Cmd+Shift+X) แล้วติดตั้ง Live Server, Prettier - Code formatter และ Auto Rename Tag

3. Emmet มีมาในตัว VS Code อยู่แล้ว เมื่อสร้างไฟล์ .html ให้พิมพ์เครื่องหมาย ! แล้วกด Tab จะได้โครงหน้า HTML5 ทันที

4. ดูผลลัพธ์โดยคลิกขวาที่ไฟล์ .html แล้วเลือก Open with Live Server หน้าเว็บจะรีเฟรชเองทุกครั้งที่บันทึกไฟล์

การจัดรูปแบบโค้ดอัตโนมัติ (Auto Format)

กด Shift+Alt+F (macOS ใช้ Shift+Option+F) เพื่อจัดย่อหน้าของไฟล์ที่เปิดอยู่ หากต้องการให้จัดรูปแบบทุกครั้งที่บันทึก ให้เปิดไฟล์ settings.json (Ctrl+Shift+P แล้วพิมพ์ Open User Settings JSON) และเพิ่มค่าต่อไปนี้

โค้ด
{

"editor.formatOnSave": true,

"editor.defaultFormatter": "esbenp.prettier-vscode"

โค้ด
}

3.2 เอลิเมนต์(Element) และแท็ก(Tag) (Duckett, 2021; บัญชา ปะสีละเตสัง, 2565)

การเขียนโค้ดในลักษณะของภาษาแบบ Markup อย่าง HTML, XML เราจะพบคำศัพท์อยู่ 2 คำที่มักจะได้ยินสลับไปสลับมากันอยู่เสมอ นั่นก็คือ คำว่า Elements (เอลิเมนต์) และ Tags (แท็ก) ซึ่งทั้ง 2 คำนี้ โดยความหมายแล้วคล้ายกัน และอาจใช้แทนกันได้ในบางกรณี แต่ความหมายที่แท้จริงของทั้ง 2 คำนี้ มีความแตกต่างกัน จะเป็นอย่างไร ลองอ่านบทความเพื่อความเข้าใจกัน ดังนี้
element คือ ส่วนประกอบที่เป็นหน่วยย่อยของโครงสร้าง HTML ในแต่ละ element จะใช้ Tag เพื่อบอกให้ทราบว่าแต่ละ element มีหน้าที่และโครงสร้างเป็นอย่างไร

ประเภทของ Element

1.Void Elements เป็นเอลิเมนต์ที่มีเพียงแท็กเปิด ได้แก่ <br> <hr> เป็นต้น

2.Row Text Elements เป็นเอลิเมนต์ที่ประกอบด้วย 3 ส่วน ได้แก่ แท็กเปิด ข้อความ และ แท็กปิด ได้แก่ <script> และ <style> เป็นต้น มีรูปแบบการเขียน เช่น

โค้ด
<style>
//เขียน css 
</style>

3.Nested Element เป็น เอลิเมนต์ที่ประกอบด้วย 3 ส่วน ดังนี้

แท็กเปิด ข้อความหรือเอลิเมนต์อื่นๆ และแท็กปิด เช่น แท็ก <ul>

โค้ด
<ul>
   <li>ข้อความแรก</li>
   <li>ข้อความที่สอง</li>
</ul>

3.3 รูปแบบมาตรฐานของ HTML

โค้ด
<html>
<head>
//ข้อความส่วนหัวของเว็บเพจ
</head>
<body>
//ข้อความส่วนเนื้อหาในเว็บเพจ
</body>
</html>

ส่วนที่1 แท็ก <html> ใช้เพื่อประกาศว่า เนื้อหาทั้งหมดที่อยู่ในแท็กนี้คือโค้ดที่จะให้เบราว์เซอร์แปลความหมายและแสดงผลลัพธ์บนเว็บเบราว์เซอร์บนจอภาพ

ส่วนที่2 แท็ก <head> ใช้เก็บคุณสมบัติของเว็บเพจ เช่น ชื่อของเว็บเพจ หรือกำหนดเป็นสไตล์ชีต ให้กับเว็บเพจ

ส่วนที่3 แท็ก <body> ใช้เก็บเนื้อหาทั้งหมดของเว็บเพจ

3.4 รูปแบบมาตรฐานของ HTML5

โค้ด
<!DOCTYPE html>
<html>
<head>
//ข้อความส่วนหัวของเว็บเพจ
</head>
<body>
//ข้อความส่วนเนื้อหาในเว็บเพจ
</body>
</html>

ส่วนที่1 แท็ก <!DOCTYPE html> ใช้ประกาศชนิดของเอกสารรวมเพื่อให้เว็บเบราว์เซอร์รับทราบและจัดเตรียมวิธีการประมวลผลสำหรับเอกสารนั้นได้อย่างถูกต้อง

ส่วนที่2 แท็ก <html> ใช้กำหนดจุดเริ่มต้นของเอกสาร HTML ในขณะที่แท็กปิดคือ </html> เป็นการกำหนดจุดสิ้นสุดของเอกสาร โดยองค์ประกอบทั้งหมดของเอกสารจะถูกกำหนดไว้อยู่ระหว่างกลางของแท็ก <html> นี้เสมอ และจะวางอยู่ใต้แท็ก <!DOCTYPE html> เสมอ

ส่วนที่3 แท็ก <head> ใช้เก็บคุณสมบัติของเว็บเพจ เช่น ชื่อของเว็บเพจ หรือกำหนดเป็นสไตล์ชีต ให้กับเว็บเพจ

และยังมีแท็ก <title> </title> อยู่ภายในได้อีกด้วย ทำหน้าที่แสดงข้อความปรากฏให้เห็นบนไตเติลบาร์หรือแทบเพจของเว็บเบราว์เซอร์ นอกจากนี้ยังมีแท็ก <meta> ใช้ในการกำหนดข้อมูลบางอย่างเกี่ยวกับเว็บเพจนั้นๆ เช่น รหัสอักขระที่ใช้ คีย์เวิร์ดสำหรับ Search Engine หรือ Refresh เบราว์เซอร์ตามเวลาที่กำหนด เป็นต้น

และยังมีแท็ก <base> ใช้ในการกำหนด URL อ้างอิงเพื่อหลีกเลี่ยงการที่จะต้องกำหนด URL แบบเต็ม ตัวอย่างเช่น

โค้ด
<head>
<base href=”https://www.google.com/img/”>
</head>
<body>
<img src=”logo.jpg”>
<img src=”nature/books.jpg”>
</body>

นอกจากมี href สำหรับกำหนดตำแหน่งของ URL อ้างอิงแล้วยังมีอีกหนึ่งแอตทริบิวคือ target ใช้สำหรับตั้งค่า base สำหรับลิงก์ไปเปิดเพจปลายทางด้วยเบราว์เซอร์ (แท็บ) ใหม่ เช่น “_blank”เป็นต้น ตัวอย่างเช่น

โค้ด
<base href=”https://www.google.co.th” target=”_blank”>

และยังมี แท็ก <style> ใช้ในการกำหนดรูปแบบด้วย CSS ตัวอย่างเช่น

โค้ด
<head>
<style>
Body {color: blue; }
</style>
</head>

และยังมี แท็ก <link> จะใช้อ้างอิงไฟล์ CSS จากภายนอก ตัวอย่างเช่น

โค้ด
<head>
<link href=”mystyle.css” rel= “stylesheet”>
</head>

และยังมีแท็ก <script> ใช้สำหรับเขียนโปรแกรมด้วยภาษา JavaScript ตัวอย่างเช่น

โค้ด
<head>
<script>
aleart(“hello world”);
</script>
</head>

ส่วนที่4 แท็ก <body> ใช้เก็บเนื้อหาทั้งหมดของเว็บเพจ

3.6 แท็กเดี่ยว

แท็กเดี่ยว คือแท็กที่เป็นแท็กเปิดอย่างเดียวไม่มีแท็กปิด ได้แก่ <p> <hr> <br> เป็นต้น ตัวอย่างแท็กเดี่ยวได้แก่

แท็ก <p> ใช้เมื่อต้องการขึ้นย่อหน้าใหม่

แท็ก <hr> ใช้เมื่อต้องการขีดเส้นตรงแนวนอน

แท็ก <br> ใช้เมื่อต้องการขึ้นบรรทัดใหม่

แท็ก <img src=”ชื่อไฟล์รูปภาพ”> ใช้เมื่อต้องการใส่รูปภาพบนเว็บไซต์

ตัวอย่างการใช้งานแท็ก <p> <hr> <br> และ <img> เช่น

โค้ด
<!DOCTYPE html>
<html lang="en">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Hello World! Site Title</title>
  </head>
  <body>
      <hr>
    <p>Hello World! My Name is Surachet Sungkhapan.
    <p>This is my website and the first time to develop it.<br>

My web is a friendly little web.<br>

Did you have a website?

โค้ด
    <hr>
    <IMG SRC="busy-as-a-bee-1641955.jpg" WIDTH="150" HEIGHT="150" ALT="Busy as a bee" BORDER="n">
  </body>
</html>

3.7 แท็กคู่

แท็กคู่ คือแท็กที่มีลักษณะเป็นแท็กเปิดและปิดคู่กัน เช่น <a>... </a> , <div>… </div> , <h1>… </h1> เป็นต้น ตัวอย่างแท็กคู่ ได้แก่

แท็ก <b> </b> ใช้สำหรับสร้างข้อความให้เป็นตัวหนา

แท็ก <u> </u> ใช้สำหรับสร้างข้อความให้เป็นตัวขีดเส้นใต้

แท็ก <i> </i> ใช้สำหรับสร้างข้อความให้เป็นตัวเอียง

แท็ก <sub> </sub> ใช้สำหรับสร้างข้อความให้เป็นตัวห้อย

แท็ก <strike> </strike> ใช้สำหรับสร้างข้อความให้เป็นตัวขีดเส้นทับ

แท็ก <li> </li> ใช้สำหรับแสดงรายการย่อย

แท็ก <ol> </ol> ใช้สำหรับแสดงรายการแบบเรียงลำดับ

แท็ก <ul> </ul> ใช้สำหรับแสดงรายการแบบไม่เรียงลำดับ

แท็ก <div> </div> ใช้สำหรับแบ่งรูปแบบการแสดงผล

แท็ก <a> </a> ใช้สำหรับสร้างลิงก์

แท็ก <span> </span> ใช้สำหรับแบ่งรูปแบบการแสดงผล โดยใช้กับข้อความสั้น

แท็ก <front> </front> ใช้สำหรับกำหนดรูปแบบตัวอักษรอยู่ใน html version 4 ปัจจุบันถูกยกเลิกไปแล้ว

แท็ก <h1> </h1> ใช้สำหรับกำหนดให้ข้อความมีขนาดใหญ่ ระดับที่1 ซึ่งมีทั้งหมด 6 ระดับ คือ h1 h2 h3 h4 h5 และ h6

ตัวอย่างการเขียนโปรแกรม

โค้ด
<!DOCTYPE html> 
<html lang="en"> 
  <head> 
    <meta charset="UTF-8"> 
    <meta name="viewport" content="width=device-width, initial-scale=1.0"> 
    <title>Hello World! Site Title</title> 
  </head> 
  <body>

3.11 แท็กโครงสร้างเชิงความหมายใน HTML5 (Semantic Elements) (จีราวุธ วารินทร์, 2564; Mozilla Developer Network [MDN], 2024)

จุดเด่นสำคัญของ HTML5 คือการนำเสนอแท็กเชิงความหมาย (Semantic Tags) ซึ่งเป็นแท็กที่บ่งบอกบทบาทหน้าที่ของเนื้อหาภายในตัวมันเอง ช่วยให้โค้ดมีความเป็นระเบียบ อ่านเข้าใจง่าย เพิ่มคะแนนการจัดอันดับการค้นหา (SEO: Search Engine Optimization) และช่วยให้โปรแกรมอ่านหน้าจอสำหรับผู้พิการ (Screen Readers) สามารถเข้าใจโครงสร้างได้อย่างสมบูรณ์ โดยแท็กสำคัญประกอบด้วย:
• <header>: กำหนดส่วนหัวของหน้าเว็บเพจหรือส่วนหัวของบทความ มักบรรจุโลโก้ ชื่อเรื่อง หรือแถบค้นหา
• <nav>: กำหนดบล็อกสำหรับลิงก์ระบบนำทางหลักของเว็บไซต์ (Navigation Links)
• <main>: กำหนดขอบเขตเนื้อหาหลักที่มีความโดดเด่นของหน้าเว็บเพจนั้น (ในแต่ละหน้าควรมี <main> เพียงอันเดียว)
• <article>: กำหนดเนื้อหาสาระที่เป็นเอกเทศในตัวเอง เช่น บทความข่าว โพสต์บล็อก หรือการ์ดรีวิวสินค้า
• <section>: กำหนดส่วนของเนื้อหาที่จัดกลุ่มตามหัวข้อที่สัมพันธ์กัน
• <aside>: กำหนดเนื้อหาเสริมด้านข้าง (Sidebar) เช่น เมนูลัด แบนเนอร์ หรือลิงก์ที่เกี่ยวข้อง
• <footer>: กำหนดส่วนท้ายของหน้าเว็บหรือส่วนท้ายของเอกสาร แสดงข้อมูลลิขสิทธิ์และช่องทางการติดต่อ

(ที่มา: World Wide Web Consortium [W3C], 2024)

3.12 การตรวจสอบความถูกต้องของฟอร์มด้วย HTML5 (Native Form Validation)

HTML5 มีกลไกตรวจสอบความถูกต้องของข้อมูลในแบบฟอร์มโดยตรงผ่านเบราว์เซอร์ ช่วยลดภาระการเขียน JavaScript ตรวจสอบเบื้องต้น (บัญชา ปะสีละเตสัง, 2565) เช่น การใช้ required เพื่อบังคับกรอก, pattern="[0-9]{10}" สำหรับหมายเลขโทรศัพท์ 10 หลัก, type="email" ตรวจสอบรูปแบบอีเมล, และ type="date" ให้เลือกวันที่ตามปฏิทินสากล

3.13 เทคนิคการใช้ AI ช่วยสร้างและตรวจสอบโครงสร้าง HTML (AI-Assisted HTML Development) (World Wide Web Consortium [W3C], 2024; Open Web Application Security Project [OWASP], 2023)

ในการพัฒนาเว็บยุคปัจจุบัน นักพัฒนาสามารถนำเครื่องมือปัญญาประดิษฐ์ (AI Assistants เช่น GitHub Copilot, ChatGPT, Gemini) มาช่วยเพิ่มความสะดวกรวดเร็วในการเขียนโค้ด HTML5 ตลอดจนตรวจสอบโครงสร้างแท็กและความถูกต้องตามมาตรฐานสากลได้อย่างมีประสิทธิภาพ

1. การแปลงเค้าโครงเป็นโค้ด HTML: นักพัฒนาสามารถบรรยายองค์ประกอบของหน้าเว็บที่ต้องการ เพื่อให้ AI ร่างโค้ดโครงสร้างตามมาตรฐาน HTML5 โดยอัตโนมัติ เช่น:
Prompt: "ช่วยสร้างโครงสร้าง HTML5 Semantic Structure สำหรับหน้าบล็อกบทความ ประกอบด้วย header, nav, main, article 2 ชิ้น, aside สำหรับบทความยอดนิยม และ footer โดยใช้แท็กที่ถูกต้องตามหลัก W3C (World Wide Web Consortium [W3C], 2024)"
2. การสร้างแบบฟอร์มพร้อมระบบตรวจสอบ (Form Validation): AI สามารถช่วยสร้างแท็ก <input> พร้อมกำหนด Attribute เช่น required, type='email', minlength, maxlength และ pattern (Regex) ช่วยลดข้อผิดพลาดในการเขียนโค้ดได้อย่างมาก

3.13.2 การให้ AI ตรวจสอบการเข้าถึงและความเข้ากันได้ (Accessibility & Semantic Audit)

• การตรวจสอบ Alt text ของรูปภาพ: นำโค้ด HTML ส่งให้ AI วิเคราะห์ว่ารูปภาพใดขาด Attribute alt หรือ alt มีข้อความที่สื่อความหมายไม่ชัดเจน
• การตรวจสอบโครงสร้างส่วนหัว (Heading Hierarchy): ให้ AI ตรวจสอบลำดับการใช้แท็ก <h1> ถึง <h6> ให้ถูกต้องเป็นลำดับชั้น โดยไม่มีการข้ามระดับ ซึ่งเป็นหัวใจสำคัญของ SEO และ Accessibility
• การผูกความสัมพันธ์ของฟอร์ม: ตรวจสอบว่าแท็ก <label for='...'> ได้เชื่อมโยงตรงกับ id ของแท็ก <input> อย่างครบถ้วนหรือไม่

3.13.3 ข้อควรระวังในการใช้ AI พัฒนา HTML

• หลีกเลี่ยงแท็กที่เลิกใช้งานแล้ว (Deprecated Tags): AI บางครั้งอาจแนะนำแท็กยุคเก่า เช่น <center>, <font>, <marquee> หรือการจัด Layout ด้วย <table> ซึ่งไม่สอดคล้องกับมาตรฐาน HTML5 ยุคปัจจุบัน นักพัฒนาต้องตรวจสอบและปรับใช้ CSS ร่วมกับ Semantic Tags เสมอ
• ตรวจสอบการปิดแท็กอย่างสมบูรณ์: แม้ว่าเบราว์เซอร์จะอนุญาตให้ละเลยการปิดแท็กบางประเภทได้ แต่การปิดแท็กอย่างครบถ้วนจะช่วยป้องกันปัญหาการเรนเดอร์ผิดพลาดในอุปกรณ์ต่าง ๆ ได้อย่างดีเยี่ยม

3.13.4 กรอบคำสั่ง AI สำหรับการตรวจสอบความเข้ากันได้และการเข้าถึง (Prompt for Accessibility Audit)

"Role: Accessibility Specialist (WCAG 2.2). / Task: Audit the following HTML code. Identify missing alt attributes, non-semantic div containers, and form inputs missing associated <label> elements. / Constraints: Rewrite the code into fully compliant Semantic HTML5 with zero validation errors on W3C Nu HTML Checker."

3.13.5 ตัวอย่างโค้ดโครงสร้าง Semantic HTML5 มาตรฐานสมบูรณ์พร้อมแบบฟอร์ม

<!DOCTYPE html>
<html lang="th">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>ระบบลงทะเบียนนักศึกษา - สาขาวิชาเทคโนโลยีดิจิทัลเพื่อธุรกิจ</title>
</head>
<body>
<header>
<nav aria-label="เมนูหลัก">
<h2>มหาวิทยาลัยนราธิวาสราชนครินทร์</h2>
<ul>
<li><a href="#home">หน้าแรก</a></li>
<li><a href="#register">ลงทะเบียน</a></li>
</ul>
</nav>
</header>
<main>
<article>
<h1>แบบฟอร์มรับสมัครนักศึกษาใหม่</h1>
<form action="process.php" method="POST">
<div>
<label for="fullname">ชื่อ-นามสกุล:*</label>
<input type="text" id="fullname" name="fullname" required minlength="3" placeholder="กรอกชื่อ-นามสกุล">
</div>
<div>
<label for="email">อีเมล:*</label>
<input type="email" id="email" name="email" required placeholder="example@domain.com">
</div>
<div>
<label for="phone">เบอร์โทรศัพท์ (10 หลัก):*</label>
<input type="tel" id="phone" name="phone" required pattern="[0-9]{10}" placeholder="0812345678">
</div>
<div>
<button type="submit">ส่งข้อมูลใบสมัคร</button>
</div>
</form>
</article>
</main>
<footer>
<p>&copy; 2026 หลักสูตรบริหารธุรกิจบัณฑิต สาขาวิชาเทคโนโลยีดิจิทัลเพื่อธุรกิจ</p>
</footer>
</body>
</html>

สรุป

ภาษา HTML เป็นภาษาโครงสร้างมาร์กอัปที่เป็นรากฐานของทุกเว็บไซต์ โดยประกอบด้วย Element, Tag เดี่ยว และ Tag คู่ ซึ่งสามารถกำหนดคุณลักษณะเพิ่มเติมผ่าน Attribute ได้ การพัฒนามาตรฐานสู่ HTML5 ได้นำเสนอแท็กเชิงความหมาย (Semantic Elements) เช่น <header>, <nav>, <main>, <article>, <section>, <footer> ซึ่งช่วยยกระดับทั้งการจัดอันดับการค้นหา (SEO) และการเข้าถึงข้อมูลตามมาตรฐานสากล นอกจากนี้ยังมีแท็กจัดการสื่อมัลติมีเดีย (<video>, <audio>, <canvas>) และการพัฒนาแบบฟอร์มที่มีระบบตรวจสอบข้อมูลในตัว การเขียน HTML5 ในยุคปัจจุบันได้รับการสนับสนุนจากเครื่องมือแก้ไขโค้ดที่ทรงพลังอย่าง VS Code ร่วมกับ Emmet และการนำผู้ช่วย AI มาประยุกต์ใช้เพื่อตรวจสอบความถูกต้อง เพิ่มความรวดเร็ว และทำให้โค้ดมีความเป็นมาตรฐานสากลสูงสุด

แบบฝึกหัด

คำชี้แจง: จงทำแบบฝึกหัดต่อไปนี้เพื่อทบทวนความรู้ความเข้าใจ

ตอนที่ 1: แบบฝึกหัดเชิงทฤษฎีและการวิเคราะห์ (Theoretical & Analytical Exercises)

1. จงอธิบายความแตกต่างระหว่าง Tag, Element และ Attribute ในภาษา HTML พร้อมยกตัวอย่างประกอบให้ชัดเจน

2. จงอธิบายความแตกต่างระหว่างแท็กคู่ (Paired Tags) และแท็กเดี่ยวหรือแท็กว่าง (Empty/Void Tags) พร้อมระบุตัวอย่างแท็กอย่างละ 3 ตัวอย่าง

3. แท็กโครงสร้างเชิงความหมาย (Semantic Elements เช่น <header>, <nav>, <main>, <article>, <footer>) ใน HTML5 มีข้อได้เปรียบเหนือการใช้แท็ก <div> เพียงอย่างเดียวอย่างไร ทั้งในแง่ของ SEO และการเข้าถึงเว็บไซต์ (Web Accessibility)

4. ในการสร้างแบบฟอร์ม (Form) บนเว็บ จงอธิบายบทบาทหน้าที่ของ Attribute name, action, และ method (GET vs POST) ว่ามีความแตกต่างกันอย่างไรในการส่งผ่านข้อมูล

5. จงอธิบายว่าปัญญาประดิษฐ์ (AI Coding Assistants) สามารถช่วยนักพัฒนาในการเขียนและตรวจสอบโค้ด HTML5 ได้อย่างไรบ้าง พร้อมยกตัวอย่าง Prompt ที่มีประสิทธิภาพในการสร้างแบบฟอร์มรับข้อมูล 1 ตัวอย่าง

ตอนที่ 2: แบบฝึกหัดประยุกต์และการเขียนโปรแกรม (Applied & Programming Exercises)

1.ให้นักศึกษาเขียนโปรแกรมเพื่อสร้างตาราง 7 คอลัมน์ 5 แถวดังนี้

2.ให้นักศึกษาเขียนโปรแกรมเพื่อสร้างแบบฟอร์มสมัครงานดังนี้

3.ให้นักศึกษาเขียนโปรแกรมสร้างลิงก์ไปยังหน้าต่าง ๆ ดังนี้
