บทนำ

ภาษาจาวาสคริปต์ (JavaScript) เป็นภาษาโปรแกรมระดับสูงเชิงวัตถุที่ทำงานทางฝั่งไคลเอนต์ (Client-Side Scripting) ซึ่งเป็นหัวใจสำคัญในการทำให้หน้าเว็บเพจมีความมีชีวิตชีวาและสามารถโต้ตอบกับผู้ใช้งาน (Interactivity) ได้อย่างราบรื่น โดยไม่จำเป็นต้องโหลดหน้าเว็บเพจใหม่ทั้งหมด จากจุดเริ่มต้นที่เป็นเพียงภาษาสคริปต์เสริมลูกเล่น ปัจจุบัน JavaScript ได้พัฒนา สู่มาตรฐาน ECMAScript (ES6+) ที่มีความทรงพลัง รองรับการจัดการโครงสร้างเอกสาร (DOM: Document Object Model), การตรวจจับเหตุการณ์ (Event Handling), การประมวลผลแบบอะซิงโครนัส (Asynchronous Programming) ร่วมกับ Fetch API และเป็นรากฐานสู่เฟรมเวิร์กสมัยใหม่ ในบทนี้นักศึกษาจะได้เรียนรู้ตั้งแต่ไวยากรณ์พื้นฐาน การควบคุม DOM ไปจนถึงการนำเครื่องมือปัญญาประดิษฐ์ (AI) มาช่วยเขียนชุดคำสั่งและแก้ไขข้อผิดพลาด (Debug) อย่างมีแบบแผน

เนื้อหา

JavaScript เป็นภาษาที่เป็น Script ที่อยู่ในเว็บไซต์ (ใช้ร่วมกับ HTML) เพื่อให้เว็บไซต์ของเราดูมีการเคลื่อนไหว สามารถตอบสนองผู้ใช้งานได้มากขึ้น โดยการใส่ JavaScript ลงในโค้ด HTML นั้นทำได้โดยใช้ แท็ก <script> โดยจะแทรกอยู่ในแท็ก <head> และ แท็ก <body>

6.1 ประโยชน์และบทบาทของภาษา JavaScript ในการพัฒนาเว็บ (จีราวุธ วารินทร์, 2566; Haverbeke, 2024)

JavaScript ใช้เมื่อต้องการให้เว็บเพจแสดงผลแบบเคลื่อนไหว ตอบสนองต่อผู้ใช้ หรือสั่งให้เบราว์เซอร์ทำงานตามที่ต้องการ ซึ่งเป็นงานที่เกินความสามารถของ HTML แต่ไม่จำเป็นต้องติดต่อกับเซิร์ฟเวอร์ เนื่องจาก JavaScript เป็นภาษาที่ทำงานฝั่งไคลเอนต์ โดยมีเบราว์เซอร์เป็นตัวแปลภาษา ตัวอย่างของงานที่ใช้ JavaScript เช่น

  • สร้างเมนูที่สามารถตอบสนองต่อการเอา mouse ไปชี้ได้
  • สร้างเครื่องคิดเลข ปฏิทิน เกม ในเว็บเพจ
  • เปิด, ปิด, เคลื่อนย้ายตำแหน่งของ window
  • ทำตัวอักษรวิ่งแบบต่างๆ
  • ตรวจสอบความถูกต้องของแบบฟอร์มที่ผู้ใช้กรอก ก่อนส่งข้อมูลไปยัง Server
  • และอื่นๆ อีกมากมายที่ไม่ต้องติดต่อกับ Server

6.2 เริ่มต้นเขียน JavaScript

การเขียน JavaScript บนไฟล์ HTML จะเริ่มจากการเปิดแท็ก <script> ก่อน ดังนี้

โค้ด
<script></script>

ตัวอย่างวิธีการเขียนโปรแกรม

โค้ด
<p id="demo"></p>
<script>
document.getElementById("demo").textContent = "ทดสอบ JavaScript";
</script>

นำโค้ดที่พิมพ์ไว้ไปวางในแท็ก <body> บนไฟล์ HTML (วางสคริปต์ไว้หลังแท็ก <p> เพื่อให้เบราว์เซอร์สร้างองค์ประกอบ demo ก่อนที่สคริปต์จะทำงาน)

myfirstjs.html

โค้ด
<!DOCTYPE html>
<html lang="th">
    <head>
        <title>ทดลองเขียน JavaScript</title>
        <meta name="viewport" content="width=device-width, initial-scale=1">
    </head>
    <body>
        <p id="demo"></p>
        <script>
            document.getElementById("demo").textContent = "ทดสอบ JavaScript";
        </script>
    </body>
</html>

เมื่อพิมพ์เสร็จแล้วให้เปิดเบราว์เซอร์โดยจะแสดงข้อความ “ทดสอบ JavaScript” ในหน้าเว็บไซต์

หมายเหตุ: คำสั่ง document.write() ที่พบในตำราเก่าไม่แนะนำให้ใช้ในปัจจุบัน เพราะหากเรียกหลังโหลดหน้าเว็บเสร็จจะลบเนื้อหาทั้งหน้า และเบราว์เซอร์บางตัวจำกัดการทำงาน ควรใช้การเข้าถึงองค์ประกอบผ่าน DOM แล้วกำหนด textContent แทน

6.3 Tag noscript

แท็ก noscript ใช้ในการรองรับกรณีที่ผู้ใช้งานไม่อนุญาตให้รันสคริปต์ หรือ เว็บเบราว์เซอร์ไม่รองรับสคริปต์ เราสามารถใส่เนื้อหาในแท็ก noscript ได้เหมือนกับแท็ก body ซึ่งจะสามารถแสดงได้เหมือนไฟล์เอกสาร html ปกติ โดยเนื้อหาภายในแท็ก noscript จะแสดงก็ต่อเมื่อเว็บเบราว์เซอร์ไม่รองรับสคริปต์หรือไม่อนุญาตให้รันสคริปต์เท่านั้น

ตัวอย่างการเขียนโปรแกรม

โค้ด
<html>
<body>
<p id="demo"></p>
<script>
document.getElementById("demo").textContent = "สวัสดีนักศึกษาทุกคน";
</script>
<noscript>เว็บเบราว์เซอร์ของคุณไม่รองรับ JavaScript!</noscript>
</body>
</html>

6.5 เพิ่มเติมสไตล์

การเพิ่มสไตล์ เช่น การสร้างปุ่ม สำหรับคลิกเลือกสีตัวอักษรที่ผู้ใช้งานต้องการให้แสดง

โค้ด
<html>
<head>
<meta charset="UTF-8">
</head>
<body>
<p id="demo">ไม่ชอบสีดำอยากเปลี่ยนเป็นแดง</p>
<button type="button" id="btnColor">คลิกตรงนี้</button>
<script>
function myFunction()
{
    document.getElementById("demo").style.color = "#ff0000";
}
document.getElementById("btnColor").addEventListener("click", myFunction);
</script>
</body>
</html>

6.6 กล่องข้อความ (Message Box)

กล่องข้อความเป็นส่วนที่ไว้สำหรับโต้ตอบกับผู้ใช้ แบ่งเป็น 3 แบบ คือ

  • กล่องการเตือน (Alert Box)

ใช้สำหรับการขึ้นข้อความเตือน ให้ผู้ใช้ระมัดระวัง หรือบอกกล่าวไปยังผู้ใช้ให้ทราบ พิจารณาคำสั่งต่อไปนี้

โค้ด
<html>
<body>
<script >
window.alert("You can't access to server!")
</script>  
</body>
</html>

6.7 การใช้งาน DOM Tree (Mozilla Developer Network [MDN], 2024)

DOM หรือ Document Object Model เป็นมาตรฐานที่ช่วยให้โปรแกรมและสคริปต์ (script) สามารถเข้าถึงและแก้ไขตัวเนื้อหา โครงสร้าง และ style ของเว็บไซต์ ปัจจุบันมาตรฐาน DOM ดูแลโดย WHATWG ในรูปแบบ DOM Living Standard

เมื่อเว็บไซต์มีการแสดงผล เบราว์เซอร์จะทำการสร้าง DOM ให้กับแต่ละหน้า

The HTML DOM Tree of Objects (จาก w3schools.com)

ในภาษา HTML จะมี HTML DOM เพื่อให้เราสามารถเขียนโค้ดในการควบคุม Element ต่าง ๆ ของ HTML ด้วย JavaScript

ตัวอย่างการใช้งาน DOM ต่อไปนี้ เป็นการเปลี่ยนเนื้อหา (ด้วย textContent) ของแท็ก <p> ที่มี id=“demo”

โค้ด
<!DOCTYPE html>
<html lang="th">
    <head>
        <title>ทดลองเขียน JavaScript</title>
        <meta name="viewport" content="width=device-width, initial-scale=1">
    </head>
    <body>
        <p id="demo"></p>        
<script>
            document.getElementById("demo").textContent = "ทดสอบ JavaScript";
            </script>
    </body>
</html>

แสดงผลลัพธ์

ตัวอย่างการเปลี่ยนเนื้อหาด้วย textContent

คำอธิบาย:

* ตั้งชื่อ id ให้กับแท็ก <p> เพื่อให้ DOM รู้ว่าจะต้องควบคุม Element ตัวใด

* โครงสร้างการใช้งาน DOM ใน JavaScript คือ “document.วิธีการ.คุณสมบัติ”

* getElementById คือ (1 ใน) วิธีการที่ใช้ควบคุม Element ของ HTML จาก id ที่ได้ตั้งเอาไว้ โดยจะต้องระบุชื่อ id ในวงเล็บด้วย มีโครงสร้างดังนี้

โค้ด
document.getElementById("id ของ Element");
* textContent คือ (1 ใน) คุณสมบัติในการเข้าถึงข้อความของ Element โดยจะแทนที่ข้อความภายใน Element นั้น ๆ และแสดงเป็นข้อความธรรมดาเสมอ (ไม่ตีความแท็ก HTML) จึงปลอดภัยต่อช่องโหว่ XSS มีโครงสร้างดังนี้
document.getElementById("id ของ Element").textContent = "ข้อความ";

หมายเหตุ: หากต้องการแทรกแท็ก HTML ลงใน Element ให้ใช้คุณสมบัติ innerHTML แต่ห้ามนำข้อความที่ผู้ใช้พิมพ์เข้ามาใส่โดยตรง เพราะเสี่ยงต่อช่องโหว่ XSS (ดูหัวข้อ 6.10.3)

ในการเพิ่มลูกเล่นให้กับเว็บไซต์เราจะใช้วิธีการวิธีหนึ่งที่มีชื่อว่า “addEventListener” ซึ่ง addEventListener จะใช้สำหรับควบคุมการใช้ Element ต่าง ๆ ของ HTML ไม่ว่าเราจะคลิกด้วยเมาส์ คีย์ข้อมูลบนคีย์บอร์ด หรือเลื่อนเมาส์ ก็จะทำให้ Element อื่น ๆ มีความเคลื่อนไหวทันที

โครงสร้างของการใช้งาน addEventListener มีดังนี้

โค้ด
document.getElementById("id ของ Element").addEventListener("วิธีการ เช่น คลิกด้วยเมาส์ คีย์ด้วยคีย์บอร์ด", ชื่อฟังก์ชัน);

ตัวอย่างเช่น

โค้ด
document.getElementById("myButton").addEventListener("click", displayMessage);

หมายถึง ถ้าคลิกปุ่ม Button จะเป็นการเรียกฟังก์ชัน displayMessage

สำหรับตัวอย่างต่อไปนี้เป็นวิธีการเพิ่มลูกเล่นให้กับปุ่ม Button โดยเมื่อคลิกปุ่ม Button จะแสดงข้อความที่แท็ก <p>

ตัวอย่างการเขียนโปรแกรม

โค้ด
<!DOCTYPE html>
<html lang="th">
    <head>
        <title>ทดลองเขียน JavaScript</title>
        <meta name="viewport" content="width=device-width, initial-scale=1">
    </head>
    <body>
        <button id="myButton">แสดงข้อความ</button>
        <p id="myMessage"></p>
        <script>
            function displayMessage() { // สร้างฟังก์ชัน
                document.getElementById("myMessage").textContent = "ทดสอบการแสดงข้อความ";
        }
        document.getElementById("myButton").addEventListener("click", displayMessage); // คลิกปุ่มเพื่อแสดงข้อความ
        </script>
    </body>
</html>

6.8 ไวยากรณ์ JavaScript สมัยใหม่ (Modern JavaScript: ECMAScript 6+) (ECMA International, 2023; Haverbeke, 2024)

มาตรฐาน ECMAScript 2015 (ES6) ถือเป็นการปฏิวัติรูปแบบการเขียนภาษา JavaScript ให้มีความปลอดภัย กระชับ และมีโครงสร้างที่เป็นระเบียบเทียบเท่าภาษาโปรแกรมเชิงวัตถุชั้นนำ โดยมีคุณสมบัติสำคัญที่นักพัฒนาเว็บต้องเข้าใจดังนี้:

6.8.1 การประกาศตัวแปรด้วย let และ const

ในอดีต JavaScript ใช้คำสั่ง var ในการประกาศตัวแปร ซึ่งมีขอบเขตการทำงานแบบ Function Scope และเกิดปัญหา Hoisting ได้ง่าย ในมาตรฐาน ES6+ จึงได้แนะนำคำสั่งประกาศตัวแปรใหม่ที่มีขอบเขตระดับบล็อก (Block Scope {}):
• const (Constant): ใช้ประกาศตัวแปรที่ค่าคงที่ ไม่สามารถกำหนดค่าใหม่ได้ เหมาะสำหรับตัวเลขอ้างอิง อาร์เรย์ หรือออบเจกต์
• let: ใช้ประกาศตัวแปรที่สามารถเปลี่ยนแปลงค่าได้ เช่น ตัวแปรนับรอบลูป หรือค่าผลลัพธ์จากการคำนวณ

ตัวอย่าง:
const TAX_RATE = 0.07;
let totalPrice = 100 * (1 + TAX_RATE);

6.8.2 ฟังก์ชันลูกศร (Arrow Functions) และ Template Literals

1. ฟังก์ชันลูกศร (Arrow Function): ช่วยลดทอนไวยากรณ์การเขียนฟังก์ชันให้สั้นกระชับ โดยใช้สัญลักษณ์ => เช่น:
// รูปแบบเดิม
function greet(name) { return 'Hello ' + name; }
// รูปแบบ Arrow Function
const greetArrow = (name) => `Hello ${name}`;

2. Template Literals: การใช้เครื่องหมาย Backtick (``) เพื่อเชื่อมต่อข้อความและแทรกค่าตัวแปรได้โดยตรงผ่าน ${ตัวแปร} ช่วยให้อ่านโค้ดได้ง่ายและรองรับการขึ้นบรรทัดใหม่อย่างสะดวก

6.8.3 การดักฟังเหตุการณ์สมัยใหม่ (Modern Event Listeners)

การเขียนคำสั่งโต้ตอบในปัจจุบันไม่นิยมใส่ onclick ใน HTML แต่จะใช้เมธอด addEventListener() เพื่อแยกโค้ด JavaScript ออกจาก HTML โดยสิ้นเชิง:
const btn = document.querySelector('#submitBtn');
btn.addEventListener('click', (event) => {
event.preventDefault(); // ป้องกันการ reload หน้าเว็บ
console.log('ปุ่มถูกคลิกเรียบร้อย');
});

6.8.4 ตัวอย่าง: สลับโหมดสว่าง/มืดด้วย classList.toggle และคำนวณราคาพร้อมภาษีแบบเรียลไทม์

6.9 การเขียนโปรแกรมแบบอะซิงโครนัสและการรับส่งข้อมูล (Async/Await & Fetch API)

ในการติดต่อกับฐานข้อมูลหรือเซิร์ฟเวอร์ภายนอกผ่าน Web API การทำงานจะใช้เวลาประมวลผลเครือข่าย JavaScript จึงใช้รูปแบบ Asynchronous เพื่อไม่ให้หน้าเว็บหยุดชะงัก (Non-blocking) โดยมีมาตรฐานการใช้งานผ่านคำสั่ง async / await ร่วมกับ fetch():

async function fetchUserData() {
try {
const response = await fetch('https://api.example.com/users');
const data = await response.json();
console.log('ข้อมูลผู้ใช้:', data);
} catch (error) {
console.error('เกิดข้อผิดพลาดในการดึงข้อมูล:', error);
}
}

การจัดเก็บข้อมูลบนเบราว์เซอร์: การใช้ localStorage ในการบันทึกสถานะของผู้ใช้ (State Persistence) ในรูปแบบ Key-Value ผ่านฟังก์ชัน JSON.stringify() และ JSON.parse() (ดูตัวอย่างในหัวข้อ 6.10.5)

6.10 เทคนิคการใช้ AI ช่วยเขียนโค้ดและดีบัก JavaScript (Haverbeke, 2024; OWASP, 2023) (AI-Assisted JS Development)

JavaScript เป็นภาษาที่มีความยืดหยุ่นสูงและมักพบข้อผิดพลาดขณะทำงาน (Runtime Errors) ได้บ่อยครั้ง การใช้เครื่องมือผู้ช่วย AI (เช่น GitHub Copilot, Cursor, ChatGPT) จึงมีประโยชน์อย่างยิ่งในการช่วยอธิบายตรรกะ การแนะนำแนวทางการเขียนโค้ด และการดีบักค้นหาจุดบกพร่อง

6.9.1 ตัวอย่าง: ดึงข้อมูลจาก JSONPlaceholder API มาแสดงในตาราง

JSONPlaceholder (jsonplaceholder.typicode.com) เป็น API ทดลองที่ให้ข้อมูลจำลองในรูปแบบ JSON ใช้ฝึก fetch() โดยไม่ต้องมีเซิร์ฟเวอร์ของตนเอง ต้องเชื่อมต่ออินเทอร์เน็ตขณะทดลอง ตัวอย่างต่อไปนี้ดึงรายชื่อผู้ใช้มาสร้างแถวของตารางด้วย DOM

โค้ด
<table id="tbl" border="1">
  <thead><tr><th>ID</th><th>ชื่อ</th><th>อีเมล</th></tr></thead>
  <tbody></tbody>
</table>
<script>
  async function loadUsers() {
    try {
      const res = await fetch('https://jsonplaceholder.typicode.com/users');
      if (!res.ok) throw new Error('HTTP ' + res.status);
      const users = await res.json();
      const tbody = document.querySelector('#tbl tbody');
      users.forEach((u) => {
        const tr = document.createElement('tr');
        [u.id, u.name, u.email].forEach((v) => {
          const td = document.createElement('td');

td.textContent = v; // ใช้ textContent เพื่อป้องกัน XSS

โค้ด
          tr.appendChild(td);
        });
        tbody.appendChild(tr);
      });
    } catch (err) {
      console.error('โหลดข้อมูลไม่สำเร็จ:', err.message);
    }
  }
  loadUsers();
</script>

6.10.1 ตัวอย่างการใช้ AI ช่วยสร้างตรรกะและการตรวจฟอร์ม (Validation)

นักพัฒนาสามารถใช้ Prompt เพื่อให้ AI ร่างฟังก์ชันการตรวจสอบข้อมูลอย่างครอบคลุม เช่น:
Prompt: "ช่วยเขียนฟังก์ชัน JavaScript (ES6) สำหรับตรวจสอบแบบฟอร์มลงทะเบียน โดยต้องตรวจว่า: 1) รหัสผ่านมีความยาวอย่างน้อย 8 ตัวอักษรและมีตัวเลขผสม 2) อีเมลถูกต้องตามรูปแบบ และ 3) แสดงข้อความเตือนใต้ช่องกรอกข้อมูลทันทีเมื่อพิมพ์ผิด (Real-time)"
AI จะสร้างฟังก์ชันพร้อม Regular Expression (Regex) และการจัดการ Event input ได้อย่างรวดเร็ว

6.10.2 การใช้ AI สำหรับการดีบักและการค้นหาข้อผิดพลาด (Console Debugging)

• การวิเคราะห์ข้อความแจ้งเตือน Error: เมื่อพบข้อผิดพลาด เช่น TypeError: Cannot read properties of undefined หรือ Uncaught SyntaxError สามารถคัดลอกข้อความใน Console ร่วมกับโค้ดส่งให้ AI ช่วยอธิบายสาเหตุและแนวทางแก้ไข
• การปรับปรุงประสิทธิภาพ (Refactoring): ให้ AI ช่วยแปลงโค้ดที่มีลูปซ้อนลูป (Nested Loops) ให้ใช้เมธอดอาร์เรย์สมัยใหม่ เช่น .map(), .filter(), .reduce() เพื่อความกระชับและรวดเร็ว

6.10.3 ข้อควรระวังด้านความมั่นคงปลอดภัยในการใช้ AI พัฒนา JavaScript

• ปัญหาช่องโหว่ Cross-Site Scripting (XSS) (Open Web Application Security Project [OWASP], 2023): AI บางครั้งอาจแนะนำการใช้ element.innerHTML ซึ่งอาจเปิดช่องโหว่ให้ผู้ไม่ประสงค์ดีแทรกโค้ดอันตราย นักพัฒนาควรเปลี่ยนไปใช้ element.textContent หรือสร้าง Element ผ่าน document.createElement() แทนเมื่อต้องแสดงผลข้อมูลจากผู้ใช้งาน
• ห้ามบันทึกความลับไว้ในโค้ดฝั่ง Client: ต้องไม่ให้ AI ฝังรหัสผ่าน API Key หรือ Secret Keys ไว้ในไฟล์ JavaScript บนเบราว์เซอร์เด็ดขาด

6.10.4 กรอบคำสั่ง AI สำหรับการดีบัก Asynchronous และการตรวจหาช่องโหว่ XSS (Prompt for Security Review)

"Role: Web Security Analyst. / Task: Review the following JavaScript DOM manipulation code. Identify potential DOM-based XSS vulnerabilities caused by unsanitized input and recommend fixes using textContent and DOMPurify. / Constraints: Refactor the code to use modern async/await with robust try...catch error handling."

6.10.5 ตัวอย่างโค้ด Modern JavaScript: การดึงข้อมูล API, LocalStorage และ DOM ปลอดภัย

สร้างไฟล์ index.html

โค้ด
<!DOCTYPE html>
<html lang="th">
<head>
  <meta charset="UTF-8">
  <title>Task Manager</title>
</head>
<body>
  <form id="task-form">
    <input type="text" id="task-input" placeholder="ชื่องาน">
    <button type="submit">เพิ่ม</button>
  </form>
  <ul id="task-list"></ul>
  <script src="app.js"></script>
</body>

สร้างไฟล์ app.js

// Task Manager Application - Modern ES6+ Safe Implementation
const taskInput = document.querySelector('#task-input');
const taskForm = document.querySelector('#task-form');
const taskList = document.querySelector('#task-list');

// โหลดรายการจาก LocalStorage เมื่อเปิดหน้าเว็บ
const loadTasks = () => {
const saved = localStorage.getItem('course_tasks');
return saved ? JSON.parse(saved) : [];
};

// บันทึกรายการลง LocalStorage
const saveTasks = (tasks) => {
localStorage.setItem('course_tasks', JSON.stringify(tasks));
};

// เรนเดอร์รายการสู่ DOM ด้วย textContent (ป้องกัน XSS จากข้อมูลที่ผู้ใช้พิมพ์)
const renderTasks = () => {
const tasks = loadTasks();
taskList.replaceChildren(); // ล้างรายการเก่า

tasks.forEach((task, index) => {
const li = document.createElement('li');
li.textContent = task.title; // ปลอดภัย: ไม่ตีความสตริงเป็น HTML

const deleteBtn = document.createElement('button');
deleteBtn.textContent = 'ลบ';
deleteBtn.addEventListener('click', () => {
tasks.splice(index, 1);
saveTasks(tasks);
renderTasks();
});

li.appendChild(deleteBtn);
taskList.appendChild(li);
});
};

// ดักจับการส่งฟอร์ม (Unobtrusive Event Handling)
taskForm.addEventListener('submit', (e) => {
e.preventDefault();
const title = taskInput.value.trim();
if (!title) return alert('กรุณากรอกชื่องาน');

const tasks = loadTasks();
tasks.push({ id: Date.now(), title: title });
saveTasks(tasks);
taskInput.value = '';
renderTasks();
});

// เริ่มต้นโหลดข้อมูล
document.addEventListener('DOMContentLoaded', renderTasks);

สรุป

ภาษา JavaScript เป็นเสาหลักสำคัญของการพัฒนาเว็บฝั่งผู้ใช้งาน (Client-Side) ที่ช่วยเปลี่ยนหน้าเว็บเอกสารนิ่ง ให้กลายเป็นเว็บแอปพลิเคชันที่มีการโต้ตอบอย่างชาญฉลาด ผ่านการควบคุมโครงสร้างเอกสาร DOM (Document Object Model) และการดักฟังเหตุการณ์ (Event Handling) ไวยากรณ์ในยุคปัจจุบันได้ก้าวสู่มาตรฐาน ES6+ ด้วยการประกาศตัวแปรที่มีขอบเขตชัดเจน (let / const), ฟังก์ชันลูกศร (Arrow Functions), และ Template Literals ควบคู่ไปกับการสื่อสารข้อมูลเครือข่ายแบบ Asynchronous ผ่าน Fetch API และการใช้คำสั่ง async/await ในการรับส่งข้อมูล JSON นอกจากนี้ การประยุกต์ใช้เครื่องมือผู้ช่วย AI เข้ามาช่วยวิเคราะห์ตรรกะ และแก้ไขข้อผิดพลาด (Debugging) ช่วยเพิ่มประสิทธิภาพการพัฒนาอย่างก้าวกระโดด โดยนักพัฒนาต้องตระหนักถึงการป้องกันช่องโหว่ความปลอดภัย เช่น XSS และการตรวจสอบความถูกต้องของโค้ดอยู่เสมอ

1. จงอธิบายความแตกต่างระหว่างการประกาศตัวแปรด้วย var, let และ const ในภาษา JavaScript โดยเน้นเรื่องขอบเขตของตัวแปร (Scope) และการกำหนดค่าใหม่

2. จงอธิบายโครงสร้างและความสัมพันธ์ของ DOM (Document Object Model) และอธิบายว่าคำสั่ง document.getElementById() กับ document.querySelector() มีข้อแตกต่างกันอย่างไร

3. เหตุใดการใช้ addEventListener() จึงเป็นแนวทางปฏิบัติที่ดี (Best Practice) มากกว่าการเขียนฟังก์ชันดักจับเหตุการณ์แบบอินไลน์ (เช่น onclick="...") ในแท็ก HTML

4. จงอธิบายแนวคิดของการเขียนโปรแกรมแบบ Synchronous และ Asynchronous ใน JavaScript ว่ามีความแตกต่างกันอย่างไร และคำสั่ง async/await ช่วยให้การเขียนโค้ดจัดการข้อมูลผ่าน fetch() มีความสะดวกขึ้นอย่างไร

5. ช่องโหว่ความปลอดภัยแบบ Cross-Site Scripting (XSS) ใน JavaScript เกิดขึ้นได้อย่างไร และเหตุใดการใช้ textContent จึงปลอดภัยกว่าการใช้ innerHTML ในการแสดงผลข้อมูลที่รับมาจากผู้ใช้งาน

6. ปัญญาประดิษฐ์ (AI Coding Assistants) สามารถช่วยเหลือนักพัฒนาในการเขียนและดีบักโค้ด JavaScript ได้อย่างไรบ้าง พร้อมยกตัวอย่างสถานการณ์ที่ AI ช่วยค้นหาข้อผิดพลาด Runtime Error

ตอนที่ 2: แบบฝึกหัดประยุกต์และการเขียนโปรแกรม (Applied & Programming Exercises)

ให้แจ้งเตือนข้อความ "Name must be filled out" หากมีค่าว่าง

2.ให้นักศึกษาเขียนโปรแกรมด้วย JavaScript สร้าง form และตรวจสอบความถูกต้อง Validation ต่าง ๆ ดังนี้

3.ให้นักศึกษาเขียนโปรแกรมด้วย JavaScript กับเทคนิค Mouseover และ Mouseout ให้ทำการเปลี่ยนสีตัวอักษรเป็นสีแดงเมื่อ Mouseover

4.ให้นักศึกษาเขียนโปรแกรมด้วย JavaScript การสลับสีแถวในตารางดังนี้
