บทนำ

ภาษา CSS (Cascading Style Sheets) เป็นกลไกสำคัญที่ใช้สำหรับกำหนดรูปแบบการแสดงผล ความสวยงาม และการจัดวางองค์ประกอบ ของเอกสาร HTML บนหน้าเว็บเพจ โดยทำหน้าที่แยกส่วนของการนำเสนอ (Presentation) ออกจากส่วนของโครงสร้างเนื้อหา (Structure) ช่วยให้การบำรุงรักษาและการปรับแต่งรูปแบบทำได้อย่างสะดวกรวดเร็วและมีมาตรฐานเดียวกันทั้งเว็บไซต์ ในบทนี้นักศึกษาจะได้เรียนรู้ตั้งแต่ รูปแบบไวยากรณ์พื้นฐาน การใช้งานตัวเลือก (Selectors), โมเดลกล่อง (Box Model: Margin, Border, Padding), เทคโนโลยีการจัดเลย์เอาต์สมัยใหม่ด้วย CSS Grid และ CSS Flexbox, การใช้งานตัวแปร (CSS Variables), การออกแบบที่ตอบสนองต่อทุกขนาดหน้าจอ (Responsive Design with Media Queries) ตลอดจนการประยุกต์ใช้ปัญญาประดิษฐ์ (AI) ในการช่วยเขียนโค้ดและแก้ไขข้อผิดพลาดทางด้านสไตล์อย่างมีประสิทธิภาพ

เนื้อหา

4.1 รูปแบบ CSS (จีราวุธ วารินทร์, 2564; Keith, 2016)

รูปแบบ CSS ประกอบด้วยตัวเลือกและบล็อกการประกาศ

อธิบายรูปแบบ CSS ได้ดังนี้

Selector (ตัวเลือก) คือส่วนที่ระบุองค์ประกอบ HTML ที่ต้องการจัดรูปแบบ
Declaration (การประกาศ) คือคำสั่งกำหนดรูปแบบ บล็อกการประกาศหนึ่งบล็อกมีได้ตั้งแต่หนึ่งการประกาศขึ้นไป
Property (คุณสมบัติ) คือชื่อลักษณะที่ต้องการกำหนด เช่น color หรือ font-size

แต่ละการประกาศประกอบด้วยชื่อคุณสมบัติและค่า โดยคั่นด้วยเครื่องหมายทวิภาค (:)
Value (ค่า) คือค่าที่กำหนดให้กับคุณสมบัตินั้น

เมื่อมีหลายการประกาศ ให้คั่นแต่ละการประกาศด้วยเครื่องหมายอัฒภาค (;) และล้อมบล็อกการประกาศด้วยเครื่องหมายปีกกา { }

4.2 CSS Style Sheet

CSS เขียนได้ 3 รูปแบบ แต่ละรูปแบบเหมาะกับวัตถุประสงค์การใช้งานต่างกัน ทั้งสามรูปแบบใช้ไวยากรณ์ของ CSS เหมือนกัน ต่างกันเพียงตำแหน่งที่เขียนคำสั่ง ได้แก่

  • Inline Style Sheet
  • Internal Style Sheet
  • External Style Sheet

4.2.1 Inline Style Sheet

Inline Style Sheet คือการเขียนคำสั่ง CSS ไว้ในแท็ก HTML โดยตรงผ่านแอตทริบิวต์ style ในรูปแบบ style="คำสั่ง CSS"

ตัวอย่างการเขียนโปรแกรม

โค้ด
<!DOCTYPE html>
<html lang="th">
<head>
<meta charset="UTF-8">
<title>Inline Style</title>
</head>
<body>
<h1 style="color: darkgreen; text-align: center;">ยินดีต้อนรับสู่ชมรมถ่ายภาพ</h1>
<p style="color: #444444; font-size: 20px;">สไตล์ถูกเขียนไว้ในแท็กนี้โดยตรง</p>
</body>
</html>

4.2.2 Internal Style Sheet

Internal Style Sheet ใช้กำหนดรูปแบบให้เฉพาะหน้าเว็บเพจหนึ่ง ๆ โดยเขียนไว้ในแท็ก <style> ภายในส่วน <head> ของหน้านั้น

ตัวอย่างการเขียนโปรแกรม

โค้ด
<!DOCTYPE html>
<html lang="th">
<head>
<meta charset="UTF-8">
<title>Internal Style</title>
<style>
  body { background-color: #fff4e0; font-family: sans-serif; }
  h1   { color: #8b3a00; }
  p    { color: #333333; }
</style>
</head>
<body>
<h1>ร้านกาแฟริมน้ำ</h1>
<p>เปิดบริการทุกวัน เวลา 08.00 - 17.00 น.</p>
</body>
</html>

4.2.3 External Style Sheet

External Style Sheet คือการเขียน CSS แยกไว้ในไฟล์ภายนอกที่มีนามสกุล .css เมื่อต้องการให้สไตล์มีผลกับเอกสาร HTML ใดให้เชื่อมโยงไฟล์ CSS นั้นเข้ากับเอกสาร ตัวอย่างนี้สร้างไฟล์สองไฟล์ในโฟลเดอร์เดียวกัน คือไฟล์ HTML และไฟล์ style.css

ตัวอย่างการเขียนโปรแกรม

โค้ด
<!DOCTYPE html>
<html lang="th">
<head>
<meta charset="UTF-8">
<title>External Style</title>
<link rel="stylesheet" href="style.css">
</head>
<body>
<h1>ห้องสมุดชุมชน</h1>
<p>เปิดให้ยืมหนังสือทุกวันเสาร์และวันอาทิตย์</p>
</body>
</html>

ส่วนในไฟล์ style.css ให้เขียนโปรแกรมดังนี้

โค้ด
body {
  background-color: #e8f4f8;
  font-family: sans-serif;
}
h1 {
  color: #15557a;
}
p {
  color: #333333;
  line-height: 1.6;
}

4.3 CSS Selectors (Mozilla Developer Network [MDN], 2024a)

ตัวเลือกใน CSS แบ่งออกเป็น 5 ประเภท ดังนี้

  • ตัวเลือกอย่างง่าย (เลือกองค์ประกอบตามชื่อ, id, คลาส)
  • ตัวเลือก Combinator (เลือกองค์ประกอบตามความสัมพันธ์เฉพาะระหว่างองค์ประกอบเหล่านั้น)
  • ตัวเลือกระดับเทียม (เลือกองค์ประกอบตามสถานะที่กำหนด)
  • ตัวเลือกองค์ประกอบหลอก (เลือกและจัดรูปแบบส่วนหนึ่งขององค์ประกอบ)
  • ตัวเลือกแอตทริบิวต์ (เลือกองค์ประกอบตามแอตทริบิวต์หรือค่าแอตทริบิวต์)

1 ตัวเลือกอย่างง่าย

ตัวเลือกอย่างง่ายประกอบไปด้วย 3 รูปแบบดังนี้

  • ตัวเลือกตามชื่อแท็ก (Element Selector): เลือกทุกองค์ประกอบที่มีชื่อแท็กตรงกับที่ระบุ

ตัวอย่างการเขียนโปรแกรม

โค้ด
<!DOCTYPE html>
<html lang="th">
<head>
<meta charset="UTF-8">
<title>Element Selector</title>
<style>
  p {
    text-align: center;
    color: #b3261e;
  }
</style>
</head>
<body>
<p>ย่อหน้าทุกตัวใช้สไตล์เดียวกัน</p>
<p id="second">ย่อหน้านี้มี id แต่ยังใช้สไตล์ของแท็ก p</p>
<p>ย่อหน้าที่สาม</p>
</body>
</html>

แสดงผลลัพธ์

  • ตัวเลือกแบบ ID: ใช้เครื่องหมาย # ตามด้วยค่า id ขององค์ประกอบ เลือกเฉพาะองค์ประกอบที่มี id ตรงกัน ซึ่งควรไม่ซ้ำกันภายในหน้าเว็บ

ตัวอย่างการเขียนโปรแกรม

โค้ด
<!DOCTYPE html>
<html lang="th">
<head>
<meta charset="UTF-8">
<title>ID Selector</title>
<style>
  #notice {
    text-align: center;
    color: #b3261e;
    font-weight: bold;
  }
</style>

<body>
<p>ย่อหน้าทั่วไปไม่ได้รับสไตล์</p>
<p id="notice">ประกาศ: ปิดทำการวันหยุดนักขัตฤกษ์</p>
<p>ย่อหน้าทั่วไปอีกตัวหนึ่ง</p>
</body>
</html>

  • ตัวเลือกแบบ Class

ตัวเลือกแบบ Class (Class Selector): ใช้เครื่องหมายจุด (.) ตามด้วยชื่อคลาส เลือกทุกองค์ประกอบที่มีแอตทริบิวต์ class ตรงกับชื่อนั้น

ตัวอย่างการเขียนโปรแกรม

<body>
<h1 class="highlight">หัวข้อที่ใช้คลาส highlight</h1>
<p class="highlight">ย่อหน้าที่ใช้คลาส highlight</p>
<p>ย่อหน้านี้ไม่ได้ระบุคลาส</p>
</body>
</html>

2 ตัวเลือก Combinator

Combinator คือสัญลักษณ์ที่ใช้อธิบายความสัมพันธ์ระหว่างตัวเลือก

ตัวเลือก CSS หนึ่งชุดประกอบด้วยตัวเลือกอย่างง่ายได้มากกว่าหนึ่งตัว โดยใช้ Combinator เชื่อมระหว่างตัวเลือกเหล่านั้น

CSS มี Combinator 4 ชนิด ได้แก่

  • ตัวเลือกผู้สืบทอด (เว้นวรรค): เลือกองค์ประกอบ <p> ทั้งหมดที่อยู่ภายในองค์ประกอบ <div>
โค้ด
div p {
    background-color: yellow;
}
  • ตัวเลือกลูก (>): เลือกเฉพาะองค์ประกอบ <p> ที่เป็นลูกโดยตรงของ <div>
โค้ด
div > p {
    background-color: yellow;
}
  • ตัวเลือกพี่น้องที่อยู่ติดกัน (+): เลือกเฉพาะองค์ประกอบ <p> ตัวแรกที่อยู่ถัดจาก <div> โดยตรงและมีพาเรนต์เดียวกัน
โค้ด
div + p {
    background-color: yellow;
}
  • ตัวเลือกพี่น้องทั่วไป (~): เลือกองค์ประกอบ <p> ทั้งหมดที่อยู่หลัง <div> และมีพาเรนต์เดียวกัน
โค้ด
div ~ p {
    background-color: yellow;
}

ตัวเลือกผู้สืบทอด

ตัวเลือกผู้สืบทอดจะจับคู่องค์ประกอบทั้งหมดที่อยู่ภายในองค์ประกอบที่ระบุ ไม่ว่าจะอยู่ลึกกี่ระดับ

ตัวอย่างต่อไปนี้เลือกองค์ประกอบ <p> ทั้งหมดภายในองค์ประกอบ <div>:

ตัวอย่างการเขียนโปรแกรม

โค้ด
<!DOCTYPE html>
<html lang="th">
<head>
<meta charset="UTF-8">
<title>Descendant Selector</title>
<style>
  div p {
    background-color: #fff3a3;
  }
</style>
</head>
<body>
<p>ย่อหน้านอก div ไม่ถูกเลือก</p>
<div>
  <p>ย่อหน้าใน div ถูกเลือก</p>
  <section>
    <p>ย่อหน้าที่อยู่ลึกลงไปอีกระดับก็ถูกเลือก</p>
  </section>
</div>
<p>ย่อหน้านอก div อีกตัวหนึ่ง</p>
</body>
</html>

3 ตัวเลือกระดับเทียม Pseudo-class

Pseudo-class (คลาสเทียม) ใช้กำหนดสถานะพิเศษขององค์ประกอบ
ตัวอย่างการใช้งาน เช่น

  • กำหนดรูปแบบเมื่อผู้ใช้เลื่อนเมาส์ไปอยู่เหนือองค์ประกอบ
  • กำหนดรูปแบบของลิงก์ที่เคยเข้าชมและยังไม่เคยเข้าชมให้แตกต่างกัน
  • กำหนดรูปแบบเมื่อองค์ประกอบได้รับโฟกัส

ตัวอย่างการเขียนโปรแกรม

โค้ด
<!DOCTYPE html>
<html lang="th">
<head>
<meta charset="UTF-8">
<title>Pseudo-class</title>
<style>
  a:link    { color: #0b57d0; }
  a:visited { color: #6a1b9a; }
  a:hover   { color: #d81b60; background-color: #fde7f0; }
  a:active  { color: #e65100; }
  input:focus {
    background-color: #e0f7fa;
    outline: 2px solid #0097a7;
  }
</style>
</head>
<body>
<p><a href="https://example.com/">ลิงก์ตัวอย่าง (เลื่อนเมาส์มาที่ลิงก์)</a></p>
<p>ชื่อ: <input type="text" value="คลิกที่ช่องนี้เพื่อดูสถานะโฟกัส"></p>
</body>
</html>

4 องค์ประกอบเทียม Pseudo-Elements

Pseudo-element (องค์ประกอบเทียม) ใช้กำหนดรูปแบบให้กับบางส่วนขององค์ประกอบ
ตัวอย่างการใช้งาน เช่น

  • กำหนดรูปแบบตัวอักษรตัวแรกหรือบรรทัดแรกขององค์ประกอบ
  • แทรกเนื้อหาก่อนหรือหลังเนื้อหาขององค์ประกอบ

รูปแบบ

โค้ด
selector::pseudo-element {
  property: value;
}

องค์ประกอบเทียมบรรทัดแรก (::first-line)
ใช้กำหนดสไตล์พิเศษให้กับบรรทัดแรกของข้อความ
ตัวอย่างต่อไปนี้กำหนดรูปแบบบรรทัดแรกของข้อความในองค์ประกอบ <p> ทุกตัว:
ตัวอย่างการเขียนโปรแกรม

โค้ด
<!DOCTYPE html>
<html lang="th">
<head>
<meta charset="UTF-8">
<title>Pseudo-element</title>
<style>
  p {
    width: 340px;
  }
  p::first-line {
    color: #0d47a1;
    font-weight: bold;
    font-size: 130%;
  }
</style>
</head>
<body>

<p>บรรทัดแรกของย่อหน้านี้จะถูกกำหนดสีและขนาดตัวอักษรต่างจากบรรทัดอื่น ส่วนข้อความที่ขึ้นบรรทัดใหม่จะแสดงผลตามปกติ</p>

โค้ด
</body>
</html>

คุณสมบัติที่ใช้ร่วมกับ ::first-line ได้ มีดังนี้

  • background properties
  • word-spacing
  • letter-spacing
  • text-decoration

  • line-height

5 ตัวเลือกแอตทริบิวต์ CSS Attribute Selectors

ลำดับความสำคัญของตัวเลือก (Specificity) และการสืบทอด (Inheritance)

เมื่อองค์ประกอบเดียวกันถูกกำหนดสไตล์ด้วยหลายกฎที่ขัดแย้งกัน เบราว์เซอร์จะตัดสินด้วยกลไกที่เรียกว่าคาสเคด (Cascade) ซึ่งพิจารณาตามลำดับดังนี้ (Mozilla Developer Network [MDN], 2024a)

1. ความสำคัญและแหล่งที่มาของกฎ: กฎที่ลงท้ายด้วย !important ชนะกฎปกติ และสไตล์ของผู้พัฒนาเว็บไซต์ชนะสไตล์เริ่มต้นของเบราว์เซอร์

2. ค่าความจำเพาะ (Specificity) ของตัวเลือก: ตัวเลือกที่ระบุองค์ประกอบได้เจาะจงกว่าจะชนะตัวเลือกที่เจาะจงน้อยกว่า

3. ลำดับการเขียน: ถ้าความจำเพาะเท่ากัน กฎที่เขียนไว้ทีหลังจะชนะ

ค่าความจำเพาะแสดงเป็นชุดตัวเลข 3 ตำแหน่ง (a, b, c) โดย a คือจำนวนตัวเลือกแบบ ID (#id) b คือจำนวนตัวเลือกแบบ Class แอตทริบิวต์ และ Pseudo-class (.class, [type], :hover) และ c คือจำนวนตัวเลือกแบบชื่อองค์ประกอบและ Pseudo-element (p, div, ::before) การเปรียบเทียบให้เทียบทีละตำแหน่งจากซ้ายไปขวา ไม่ใช่การบวกรวมเป็นตัวเลขเดียว ตัวอย่างเช่น p มีค่า (0, 0, 1) .note มีค่า (0, 1, 0) p.note มีค่า (0, 1, 1) #menu li.active มีค่า (1, 1, 1) และสไตล์ที่เขียนในแอตทริบิวต์ style ของแท็กโดยตรง (Inline Style) มีน้ำหนักสูงกว่าตัวเลือกทุกชนิดในสไตล์ชีต ยกเว้นกฎที่ใช้ !important

โค้ด

<html lang="th">
<head>
<meta charset="UTF-8">

<style>

p { color: black; } /* (0, 0, 1) */

โค้ด
  .note  { color: blue;  }   /* (0, 1, 0) */

p.note { color: green; } /* (0, 1, 1) */

โค้ด
  #msg   { color: red;   }   /* (1, 0, 0) */
</style>
</head>
<body>

<p class="note">ย่อหน้าที่มี class</p>
<p id="msg" class="note">ย่อหน้าที่มี id และ class</p>

ย่อหน้าแรกแสดงเป็นสีดำตามกฎ p ย่อหน้าที่สองเป็นสีเขียวเพราะ p.note (0, 1, 1) มีความจำเพาะสูงกว่า p และ .note ส่วนย่อหน้าที่สามเป็นสีแดงเพราะตัวเลือก #msg (1, 0, 0) มีความจำเพาะสูงที่สุด แม้จะเขียนไว้ก่อนกฎอื่นก็ตาม

การสืบทอด (Inheritance) คือการที่คุณสมบัติบางชนิดถูกส่งต่อจากองค์ประกอบแม่ (Parent) ไปยังองค์ประกอบลูกโดยอัตโนมัติ คุณสมบัติที่สืบทอดได้ส่วนใหญ่เป็นกลุ่มข้อความ เช่น color, font-family, font-size, font-style, font-weight, line-height และ text-align ส่วนคุณสมบัติที่เกี่ยวกับกล่อง เช่น margin, padding, border, background และ width ไม่ถูกสืบทอด ค่าที่สืบทอดมามีลำดับต่ำที่สุด ถ้าองค์ประกอบลูกมีกฎของตนเองตรงกับคุณสมบัตินั้น จะใช้กฎของตนเองเสมอไม่ว่าความจำเพาะจะต่ำเพียงใด

นักพัฒนาสามารถควบคุมการสืบทอดด้วยค่าพิเศษ 3 ค่า ได้แก่ inherit บังคับให้รับค่าจากองค์ประกอบแม่ initial ใช้ค่าเริ่มต้นของคุณสมบัตินั้น และ unset ทำงานเหมือน inherit กับคุณสมบัติที่สืบทอดได้ และเหมือน initial กับคุณสมบัติที่สืบทอดไม่ได้ ตัวอย่างเช่น

โค้ด
body { color: #333; font-family: sans-serif; }

a { color: inherit; } /* ลิงก์ใช้สีเดียวกับข้อความรอบข้าง */

แนวปฏิบัติที่ควรจำ: ใช้ Class แทน ID ในการจัดสไตล์ เพื่อให้ความจำเพาะต่ำและแก้ไขทับได้ง่าย หลีกเลี่ยงตัวเลือกที่ซ้อนกันหลายระดับ และใช้ !important เฉพาะกรณีจำเป็นจริง ๆ เมื่อสไตล์ไม่แสดงผลตามที่ตั้งใจ ให้เปิดแท็บ Styles ในเครื่องมือพัฒนาของเบราว์เซอร์ (DevTools) กฎที่ถูกขีดฆ่าคือกฎที่แพ้ในการตัดสินของคาสเคด ทำให้ตรวจได้ทันทีว่ากฎใดถูกนำไปใช้

4.5 CSS Borders

คุณสมบัติเกี่ยวกับเส้นขอบ (border) ของ CSS ช่วยให้กำหนดรูปแบบ ความกว้าง และสีของเส้นขอบขององค์ประกอบได้

CSS Border Style

คุณสมบัติ border-style ระบุชนิดของเส้นขอบที่แสดง

ค่าที่ใช้ได้ มีดังนี้

  • dotted - เส้นขอบแบบจุด
  • dashed - เส้นขอบแบบเส้นประ
  • solid - เส้นขอบแบบเส้นทึบ
  • double - เส้นขอบแบบเส้นคู่
  • groove - เส้นขอบสามมิติแบบร่อง ลักษณะที่เห็นขึ้นกับค่า border-color
  • ridge - เส้นขอบสามมิติแบบสัน ลักษณะที่เห็นขึ้นกับค่า border-color
  • inset - เส้นขอบสามมิติแบบกดลง ลักษณะที่เห็นขึ้นกับค่า border-color
  • outset - เส้นขอบสามมิติแบบนูนขึ้น ลักษณะที่เห็นขึ้นกับค่า border-color
  • none - ไม่มีเส้นขอบ
  • hidden - เส้นขอบแบบซ่อน

คุณสมบัติ border-style กำหนดค่าได้ตั้งแต่หนึ่งถึงสี่ค่า (สำหรับเส้นขอบด้านบน ขวา ล่าง และซ้ายตามลำดับ)

4.6 CSS Margins

คุณสมบัติ margin (ระยะขอบ) ใช้สร้างพื้นที่ว่างรอบองค์ประกอบ โดยอยู่นอกเส้นขอบขององค์ประกอบ

ผู้พัฒนาสามารถกำหนดระยะขอบของแต่ละด้านขององค์ประกอบได้อย่างอิสระ (ด้านบน ขวา ล่าง และซ้าย)

ระยะขอบแต่ละด้าน
CSS มีคุณสมบัติสำหรับกำหนดระยะขอบของแต่ละด้านขององค์ประกอบ ดังนี้

  • margin-top
  • margin-right
  • margin-bottom
  • margin-left

คุณสมบัติระยะขอบทุกตัวรับค่าต่อไปนี้ได้

  • auto - ให้เบราว์เซอร์คำนวณระยะขอบเอง
  • length - ระบุเป็นหน่วยความยาว เช่น px, pt, cm
  • % - ระบุเป็นร้อยละของความกว้างขององค์ประกอบที่บรรจุอยู่
  • inherit - สืบทอดค่าระยะขอบจากองค์ประกอบพาเรนต์

หมายเหตุ: ระยะขอบกำหนดเป็นค่าลบได้

คุณสมบัติ float กำหนดการลอยตัวขององค์ประกอบ ส่วนคุณสมบัติ clear กำหนดว่าองค์ประกอบใดไม่ให้ลอยอยู่ติดด้านใดขององค์ประกอบที่ลอยตัว

คุณสมบัติ float
คุณสมบัติ float ใช้กำหนดตำแหน่งและการจัดวางเนื้อหา เช่น ให้รูปภาพลอยไปทางซ้ายของข้อความภายในคอนเทนเนอร์
คุณสมบัติ float รับค่าได้ดังนี้
left - องค์ประกอบลอยไปทางซ้ายของคอนเทนเนอร์

img {
float: left;
}
right - องค์ประกอบลอยไปทางขวาของคอนเทนเนอร์

img {
float: right;
}
none - องค์ประกอบไม่ลอย (แสดงตามตำแหน่งปกติในเนื้อหา) เป็นค่าเริ่มต้น

img {
float: none;
}
inherit - องค์ประกอบสืบทอดค่า float จากพาเรนต์

4.9 CSS Grid Layout Module

CSS Grid Layout Module เป็นระบบจัดวางแบบกริดที่ประกอบด้วยแถวและคอลัมน์ ช่วยให้ออกแบบหน้าเว็บได้ง่ายขึ้นโดยไม่ต้องใช้ float และ position

องค์ประกอบกริด
เลย์เอาต์กริดประกอบด้วยองค์ประกอบหลัก (คอนเทนเนอร์) และองค์ประกอบย่อยตั้งแต่หนึ่งรายการขึ้นไป

คอนเทนเนอร์กริด
การทำให้องค์ประกอบ HTML เป็นคอนเทนเนอร์กริดต้องกำหนดคุณสมบัติ display เป็น grid หรือ inline-grid
คอนเทนเนอร์กริดประกอบด้วยรายการกริดที่วางอยู่ในคอลัมน์และแถว

คุณสมบัติ grid-template-columns

4.11 CSS Flexbox

ใน CSS การกำหนดขนาดและตำแหน่งของกล่องใช้โหมดการจัดวาง (Layout Mode) ซึ่งมีดังนี้

  • block - จัดวางเนื้อหาแบบบล็อก
  • inline - จัดวางเนื้อหาต่อเนื่องในบรรทัดเหมือนข้อความ
  • table - จัดวางเนื้อหาแบบตาราง
  • position - กำหนดตำแหน่งขององค์ประกอบได้อย่างอิสระ

เมื่อเว็บสมัยใหม่มีความซับซ้อนมากขึ้น โหมดการจัดวางแบบเดิมทำให้เขียนโค้ดไม่สะดวก CSS3 จึงเพิ่มโหมดใหม่ที่เรียกว่า Flex Layout หรือ Flexible Box (Flexbox) ซึ่งช่วยให้กล่องมีความยืดหยุ่นมากขึ้น

Flex Layout คล้ายกับ block layout แต่ไม่ใช้คุณสมบัติบางตัว เช่น float และมีคุณสมบัติใหม่เพิ่มขึ้น ความสามารถหลักของ Flex Layout ได้แก่

  • ทิศทาง (Orientation): กำหนดแนวการเรียงกล่องได้ ทั้งบนลงล่าง ล่างขึ้นบน ซ้ายไปขวา และขวาไปซ้าย
  • ขนาด (Sizing): กำหนดให้ขนาดกล่องปรับตามพื้นที่ว่างที่เหลือได้โดยอัตโนมัติ
  • ลำดับ (Ordering): เลือกลำดับการแสดงผลของกล่องได้ และลำดับอาจแตกต่างกันตามขนาดของวิวพอร์ต (Viewport)
  • การจัดแนว (Alignment): กำหนดการจัดแนวกล่องได้ ทั้งชิดซ้าย กึ่งกลาง และชิดขวา ทั้งแนวนอนและแนวตั้ง

การใช้งาน Flexbox

การใช้ความสามารถของ Flexbox ต้องสร้าง Flex Container ก่อน โดยปกติการกำหนดโหมดการจัดวาง (Layout Mode) ให้กับองค์ประกอบใดจะกำหนดคุณสมบัติ display ไว้ที่องค์ประกอบนั้น แต่สำหรับ Flexbox ต้องกำหนดคุณสมบัติ display ไว้ที่องค์ประกอบที่เป็นคอนเทนเนอร์แทน ดังตัวอย่างโค้ดต่อไปนี้

4.12 ตัวแปรใน CSS และหน่วยวัดสมัยใหม่ (CSS Custom Properties & Modern Units) (Verou, 2015)

CSS Custom Properties หรือที่นิยมเรียกว่า "ตัวแปรใน CSS (CSS Variables)" เป็นคุณสมบัติสำคัญที่ช่วยให้นักพัฒนา สามารถประกาศค่าข้อมูล เช่น ค่าสี ขนาดแบบอักษร หรือระยะห่าง ไว้ที่จุดเดียว แล้วนำไปอ้างอิงใช้ซ้ำได้ทั่วทั้งสไตล์ชีต ช่วยเพิ่มความเป็นระเบียบและทำให้การสลับธีมสี (เช่น Dark Mode / Light Mode) ทำได้อย่างมีประสิทธิภาพสูง

4.12.1 การประกาศและเรียกใช้งานตัวแปรใน CSS

การประกาศตัวแปรส่วนกลางมักประกาศไว้ภายใน Pseudo-class :root เพื่อให้สามารถเรียกใช้งานได้จากทุกองค์ประกอบในหน้าเว็บ:
:root {
--primary-color: #0d6efd; /* สีหลักของแบรนด์ */
--secondary-color: #6c757d; /* สีรอง */
--base-font-size: 16px; /* ขนาดฟอนต์พื้นฐาน */
--border-radius: 8px; /* ความโค้งมนของขอบ */
}

เมื่อต้องการนำตัวแปรไปใช้งาน จะใช้ฟังก์ชัน var() เช่น:
button.btn-primary {
background-color: var(--primary-color);
border-radius: var(--border-radius);
color: #ffffff;
}

4.12.2 หน่วยวัดสัมพัทธ์สมัยใหม่ (Modern CSS Units)

เพื่อรองรับการแสดงผลบนอุปกรณ์ที่มีความละเอียดแตกต่างกัน นักพัฒนาควรเลือกใช้หน่วยวัดแบบสัมพัทธ์ (Relative Units) แทนหน่วยคงที่ (px):
• rem (Root EM): อิงตามขนาดตัวอักษรของแท็ก <html> (ค่าเริ่มต้นมาตรฐานคือ 1rem = 16px) เหมาะสำหรับการกำหนดขนาดตัวอักษรและระยะ Margin/Padding
• em: อิงตามขนาดตัวอักษรของ Element แม่ (Parent Element)
• vw (Viewport Width) และ vh (Viewport Height): เทียบเป็นร้อยละของความกว้างและความสูงของหน้าจอเบราว์เซอร์ (100vh = เต็มความสูงหน้าจอ)
• ฟังก์ชันคำนวณขั้นสูง: clamp(min, preferred, max) ช่วยควบคุมขนาดตัวอักษรหรือเลย์เอาต์ให้ยืดหยุ่นระหว่างค่าต่ำสุดและสูงสุดโดยอัตโนมัติ

4.13 การออกแบบตอบสนองด้วยมีเดียคิวรี (Responsive Web Design with Media Queries) (Keith, 2016; Coyier, n.d.-a, n.d.-b)

มีเดียคิวรี (Media Queries) เป็นหัวใจสำคัญของ Responsive Web Design โดยช่วยให้ CSS สามารถตรวจสอบขนาดหน้าจอ ความละเอียด และทิศทางการแสดงผลของอุปกรณ์ จากนั้นจึงเลือกใช้ชุดคำสั่งสไตล์ที่เหมาะสมกับอุปกรณ์นั้น ๆ โดยอัตโนมัติ

ตัวอย่างการเขียน Media Queries ตามแนวคิด Mobile-First:
/* สไตล์เริ่มต้นสำหรับหน้าจอขนาดเล็ก (สมาร์ตโฟน) */
.container {
width: 100%;
display: flex;
flex-direction: column;
}

/* เมื่อขนาดหน้าจอมีขนาดตั้งแต่ 768px ขึ้นไป (แท็บเล็ตและเดสก์ท็อป) */
@media (min-width: 768px) {
.container {
flex-direction: row; /* สลับการจัดวางเป็นแนวนอน */
justify-content: space-between;
}
}

4.14 เทคนิคการใช้ AI ช่วยกำหนดสไตล์และจัดเลย์เอาต์ CSS (Verou, 2015; Coyier, n.d.-a, n.d.-b) (AI-Assisted CSS Development)

การจัดการเลย์เอาต์และคุณสมบัติทางด้านภาพของ CSS มักมีความซับซ้อน โดยเฉพาะการจัดวางแบบ Flexbox, Grid และการสร้าง Animation ที่สวยงาม เครื่องมือผู้ช่วย AI (เช่น GitHub Copilot, Cursor, ChatGPT) จึงเข้ามามีบทบาทอย่างยิ่งในการช่วยร่างสไตล์และแก้ปัญหา

4.14.1 การสร้างเลย์เอาต์และการจัดสไตล์ด้วยคำสั่งภาษาธรรมชาติ

นักพัฒนาสามารถบรรยายการจัดวางที่ต้องการเพื่อให้ AI สังเคราะห์โค้ด CSS ที่กระชับและถูกต้องตามมาตรฐาน เช่น:
Prompt: "ช่วยเขียน CSS Flexbox เพื่อจัดให้การ์ดสินค้า 3 ใบเรียงตัวแนวนอนและอยู่กึ่งกลางหน้าจอ โดยเมื่อดูบนหน้าจอมือถือ (<768px) ให้เรียงตัวแนวตั้ง และใส่เงาแบบนุ่มนวล (Soft Box-Shadow)"
AI จะสร้างโค้ดที่มีทั้งการตั้งค่า display: flex, justify-content: center, gap, และ @media ให้เสร็จสิ้นทันที

4.14.2 การใช้ AI ค้นหาและแก้ไขปัญหาเลย์เอาต์แตก (CSS Debugging)

• การตรวจสอบปัญหา Overflow: เมื่อหน้าเว็บเกิดแถบเลื่อนแนวนอน (Horizontal Scroll) โดยไม่พึงประสงค์ สามารถส่งโค้ด HTML/CSS ให้ AI วิเคราะห์ว่าเกิดจาก Element ใดที่มีความกว้างเกินขนาดหน้าจอ
• การวิเคราะห์ลำดับความสำคัญ (CSS Specificity Conflicts): ช่วยวิเคราะห์หาสาเหตุที่สไตล์ที่เขียนไม่แสดงผลอันเนื่องมาจากความสำคัญของตัวเลือก (ID vs Class vs Inline) ทับซ้อนกัน
• การแปลงโค้ดแบบดั้งเดิม (float) สู่ Flexbox/Grid: ให้ AI ปรับปรุงโค้ดเลย์เอาต์ยุคเก่าให้กลายเป็นมาตรฐานสมัยใหม่ที่สะอาดและยืดหยุ่นขึ้น

4.14.3 ข้อควรระวังในการใช้ AI พัฒนา CSS

• หลีกเลี่ยงการใช้ !important พร่ำเพรื่อ: AI มักแก้ปัญหาความสำคัญของสไตล์ด้วยการเติม !important ซึ่งเป็นแนวทางปฏิบัติที่ไม่ดี (Bad Practice) ทำให้อนาคตแก้ไขได้ยาก นักพัฒนาต้องปรับที่โครงสร้างตัวเลือกให้เหมาะสม
• การทดสอบข้ามเบราว์เซอร์ (Cross-Browser Testing): คุณสมบัติ CSS ใหม่ ๆ บางรายการอาจยังไม่รองรับในเบราว์เซอร์รุ่นเก่า ต้องตรวจสอบตารางความเข้ากันได้ (Can I use?) เสมอ

4.14.4 กรอบคำสั่ง AI สำหรับการดีบักปัญหาเลย์เอาต์ CSS (Prompt for CSS Debugging)

"Role: Senior CSS Architect. / Task: Analyze the CSS rules causing horizontal overflow (horizontal scrollbar appearing on mobile screens < 576px). / Constraints: Identify elements exceeding 100vw, provide fix using box-sizing: border-box, and enforce modern CSS clamp() for responsive typography."

สรุป

ภาษา CSS เป็นเครื่องมือหลักในการตกแต่งและจัดการแสดงผลของหน้าเว็บเพจ โดยสามารถประยุกต์ใช้งานได้ 3 รูปแบบ ได้แก่ Inline Styles, Internal Style Sheet และ External Style Sheet การเข้าใจตัวเลือก (Selectors) และโมเดลกล่อง (Box Model: Content, Padding, Border, Margin) เป็นพื้นฐานสำคัญที่สุดในการควบคุมพื้นที่ การจัดวางโครงสร้างเว็บไซต์ยุคใหม่ได้ก้าวหน้าจากระบบ Float สู่มาตรฐาน CSS Flexbox สำหรับการจัดวาง 1 มิติ และ CSS Grid Module สำหรับการจัดวาง 2 มิติที่มีความซับซ้อนสูง นอกจากนี้ การประยุกต์ใช้ตัวแปรใน CSS (CSS Variables) หน่วยวัดสัมพัทธ์ (rem, vh, vw) และมีเดียคิวรี (Media Queries) ช่วยให้เว็บไซต์สามารถตอบสนองต่อทุกอุปกรณ์ (Responsive Web Design) ได้อย่างสมบูรณ์แบบ การผสานการทำงานร่วมกับผู้ช่วย AI จะช่วยให้นักพัฒนาเขียนสไตล์ชีตได้อย่างรวดเร็ว แก้ปัญหาการจัดวางได้อย่างแม่นยำ และคงไว้ซึ่งโค้ดที่มีประสิทธิภาพสูงตามมาตรฐานสากล
