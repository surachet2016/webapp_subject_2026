ใบงานที่ 9: จัดทำเว็บไซต์ด้วย WordPress (Block Editor & AI Integration)

9.1 โปรแกรมสำเร็จรูป WordPress, Joomla (จีราวุธ วารินทร์, 2565; วิศัลย์ ลักษมีวาสิน, 2566)

CMS = ระบบที่ให้คนทั่วไปจัดการเนื้อหาได้เอง

เขียนเอง (บทที่ 3–8)

ควบคุมได้ทุกจุด เหมาะกับระบบเฉพาะทาง เช่น ระบบลงทะเบียน แต่ใช้เวลาและต้องมีนักพัฒนาดูแล

WordPress

เริ่มจากบล็อก ใช้ง่าย ธีมและปลั๊กอินมาก เหมาะกับเว็บองค์กร ข่าว ร้านค้า (WooCommerce)

Joomla!

จัดการสิทธิผู้ใช้และหลายภาษาได้ละเอียดในตัว เหมาะกับพอร์ทัลหรือเว็บที่มีสมาชิกหลายระดับ

ทั้งสองระบบสร้างด้วย PHP + MySQL ที่เรียนในบทที่ 7–8 จึงติดตั้งบน XAMPP/MAMP ได้ และแก้ไขธีมได้เมื่อเข้าใจโค้ด

WordPress.orgดาวน์โหลดและเอกสาร Joomla.orgดาวน์โหลด Joomla! Joomla! Documentationคู่มือการใช้งาน

9.1.1 เหตุผล 5 ประการที่ควรเลือกใช้ WordPress

คลิกการ์ดเพื่อดูเหตุผล

1ประหยัดเงินและเวลา
ตัวระบบฟรี ธีมสำเร็จรูปช่วยให้ขึ้นเว็บได้ในไม่กี่วัน ค่าใช้จ่ายหลักคือโฮสติ้งและโดเมน
2คนทั่วไปใช้ได้
เขียนบทความผ่านหน้าแอดมินคล้ายโปรแกรมพิมพ์เอกสาร เจ้าหน้าที่อัปเดตข่าวเองได้
3ยืดหยุ่นสูง
เปลี่ยนธีมได้ เพิ่มความสามารถด้วยปลั๊กอิน เช่น ฟอร์ม ร้านค้า หลายภาษา
4SEO และมือถือ
ลิงก์ถาวรอ่านง่าย ธีมสมัยใหม่รองรับหน้าจอมือถือ มีปลั๊กอินช่วยทำ SEO
5ความปลอดภัย
มีทีมดูแลและออกอัปเดตสม่ำเสมอ แต่ปลอดภัยจริงเมื่อผู้ดูแลอัปเดตและตั้งค่าถูกต้อง (9.4)

ข้อเสียที่ต้องรู้: ปลั๊กอินมากเกินทำให้ช้าและเสี่ยง ต้องอัปเดตสม่ำเสมอ และระบบเฉพาะทางอาจต้องเขียนเอง

9.2 การใช้งานโปรแกรมสำเร็จรูป WordPress

ติดตั้งบนเครื่องตัวเองใน 5 ขั้น

9.2.1 การตั้งค่าลิงก์ถาวร (Permalinks)

URL ที่คนอ่านออก ดีต่อผู้ใช้และ SEO

Settings › Permalinks

ถ้าเลือก Post name แล้วหน้าอื่นขึ้น 404 ให้เปิด LoadModule rewrite_module (ลบ # หน้าบรรทัด) และตั้ง AllowOverride All แล้วรีสตาร์ต Apache · ผู้เขียนทดสอบกับ MAMP 7.4 แล้ว

9.2.2 การติดตั้งปลั๊กอินแบบฟอร์มติดต่อ

ปลั๊กอินฟอร์มติดต่อ ตัวไหนน่าติดตั้ง?

ข้อมูลปลั๊กอินด้านล่างเป็นตัวอย่างสมมติเพื่อฝึกพิจารณา คลิกตัวที่คิดว่าเหมาะที่สุด

Quick Contact Pro

อัปเดตล่าสุด 3 ปีที่แล้ว · ติดตั้ง 2,000+ · ทดสอบถึง WP 5.8 · ⭐ 3.1

Simple Form Builder

อัปเดตล่าสุด 2 สัปดาห์ · ติดตั้ง 1 ล้าน+ · ทดสอบถึงรุ่นล่าสุด · ⭐ 4.6 · มีระบบกันสแปม

Mega Forms (Nulled)

ดาวน์โหลดจากเว็บแจกฟรี · รุ่น Pro ที่ปกติขาย · ไม่มีอัปเดต · ไม่ทราบผู้พัฒนา

เกณฑ์: อัปเดตสม่ำเสมอ · รองรับ WordPress รุ่นที่ใช้ · ผู้ใช้มาก คะแนนดี · ดาวน์โหลดจากแหล่งทางการ · ติดตั้งเท่าที่จำเป็น

9.3.1 การจัดเนื้อหาด้วยระบบบล็อก (Block-Based Architecture) (WordPress.org, 2024)

ทุกอย่างคือบล็อก ลองเพิ่ม ลบ สลับลำดับ

คลิกข้อความเพื่อแก้ไขได้ · ชี้บล็อกเพื่อเลื่อนขึ้น ลง หรือลบ

สิ่งที่ WordPress บันทึกลงฐานข้อมูล (post_content)

9.3.2 แนวคิด Full Site Editing (FSE)

แก้ทั้งเว็บด้วยบล็อก ไม่ใช่แค่เนื้อหา

Template Part: Header
Template: Single PostPost Content (บล็อกจากบทความ)
Template Part: Footer

คลิกส่วนต่าง ๆ ทางซ้าย

เพื่อดูว่าแต่ละส่วนแก้ที่ไหน

ใช้กับธีมแบบบล็อก (Block Theme) เช่น ธีมค่าเริ่มต้นรุ่นใหม่ของ WordPress · เมนู Appearance › Editor

9.4 การรักษาความมั่นคงปลอดภัยและการบำรุงรักษาระบบ CMS (OWASP, 2023c; วิศัลย์ ลักษมีวาสิน, 2566)

เช็กลิสต์ดูแลเว็บ WordPress

สถานะความปลอดภัย

ช่องโหว่ส่วนใหญ่ของ CMS มาจากปลั๊กอินที่ไม่อัปเดตและรหัสผ่านอ่อน ตรงกับหมวด Vulnerable Components และ Authentication Failures ของ OWASP Top 10

9.4.1 ตัวอย่างโค้ดเสริมความปลอดภัยในไฟล์ wp-config.php และ .htaccess

คลิกแต่ละบรรทัดเพื่อดูความหมาย

คลิกบรรทัดทางซ้าย

9.4.2 สิทธิการใช้งานของธีมและปลั๊กอิน (GPL) (WordPress.org, 2024)

GPL ให้เสรีภาพ 4 ข้อ ลองตอบ ถูก หรือ ผิด

  1. ใช้งานได้ทุกวัตถุประสงค์
  2. ศึกษาและแก้ไขซอร์สโค้ด
  3. แจกจ่ายสำเนาต่อ
  4. แจกจ่ายฉบับที่แก้ไขแล้ว

ฉบับที่แจกต่อต้องเป็น GPL ด้วย (Copyleft) · GPL ไม่ได้แปลว่าต้องฟรี

9.5.3 กรอบคำสั่ง AI สำหรับการสร้างบทความและเพิ่มประสิทธิภาพ SEO

AI ช่วยร่าง มนุษย์ตรวจและรับผิดชอบ

Role: SEO Content Strategist Task: เขียนบทความภาษาไทย 800 คำ หัวข้อ "เทรนด์การพัฒนาเว็บปี 2026" Constraints: - Focus Keyword - Meta Title ไม่เกิน 60 ตัวอักษร - Meta Description ไม่เกิน 160 ตัวอักษร - หัวข้อย่อย H2/H3 ตามโครงสร้างเนื้อหา - ข้อความ Alt ของภาพประกอบ 3 ภาพ - ระบุแหล่งอ้างอิงที่ตรวจสอบได้

ปรับจากตัวอย่างในหัวข้อ 9.5.3

ข้อควรระวังทางจริยธรรม

  • ตรวจข้อเท็จจริงทุกข้อ AI อาจแต่งข้อมูล (Hallucination)
  • ไม่ผลิตบทความขยะจำนวนมากเพื่อปั่นอันดับ
  • ภาพจาก AI ตรวจสิทธิ์และระบุว่าสร้างด้วย AI
  • อ้างอิงแหล่งที่มา ไม่คัดลอกงานผู้อื่น
  • ไม่ใส่ข้อมูลส่วนบุคคลของสมาชิกเว็บลงใน AI

สรุปบทที่ 9

CMS ช่วยให้สร้างเว็บเร็ว แต่ผู้ดูแลต้องรับผิดชอบ

  • WordPress/Joomla สร้างด้วย PHP + MySQL ติดตั้งบน XAMPP/MAMP ได้
  • ตั้ง Permalink เป็น Post name · เลือกปลั๊กอินจากแหล่งทางการ
  • Block Editor และ Full Site Editing จัดเนื้อหาและโครงหน้าด้วยบล็อก
  • อัปเดต สำรองข้อมูล 2FA สิทธิผู้ใช้ และเคารพ GPL
  • AI ช่วยเขียนและทำ SEO แต่มนุษย์ต้องตรวจเสมอ
