5.5 Bootstrap5 Form Validation

บอกผู้ใช้ว่าช่องไหนถูก ช่องไหนต้องแก้

  • .was-validated ที่ <form> สั่งให้แสดงผลการตรวจ (ขอบเขียว/แดง)
  • .valid-feedback ข้อความเมื่อถูก
  • .invalid-feedback ข้อความเมื่อผิด
  • อาศัย required, type, pattern ของ HTML5 (บทที่ 3)

5.8 AI-Assisted Bootstrap UI (ศุภชัย สมพานิช, 2566ข)

ให้ AI ร่าง แล้วเราตรวจเวอร์ชันและการเข้าถึง

บทบาท: นักพัฒนา Front-end ที่ใช้ Bootstrap 5.3 งาน: ร่างหน้าแดชบอร์ดผู้ดูแลร้านกาแฟ ส่วนประกอบ: navbar, sidebar ซ่อนได้บนมือถือ, การ์ดสรุปยอด 4 ใบ, ตารางคำสั่งซื้อล่าสุด ข้อกำหนด: ใช้คลาส Bootstrap 5 เท่านั้น (ไม่ใช้ jQuery), responsive ด้วย col-12 col-md-6 col-xl-3, ทุกปุ่มและฟอร์มมี label, ใช้ข้อมูลสมมติ ผลลัพธ์: ไฟล์ HTML เดียว พร้อมคำอธิบายโครงสร้าง

ตัวอย่างกรอบคำสั่งจากหัวข้อ 5.8.3

ข้อควรระวัง (5.8.2)

  • AI มักปนคลาสของ Bootstrap 3/4 เช่น ml-3, float-right, form-group
  • ใช้ data-toggle แทน data-bs-toggle ทำให้ปุ่มไม่ทำงาน
  • แนบ jQuery โดยไม่จำเป็น
  • ตรวจกับเอกสาร v5.3 และทดสอบทุกขนาดจอ
  • ไม่ใส่ข้อมูลจริงของลูกค้าใน Prompt

สรุปบทที่ 5

Bootstrap ช่วยให้เร็ว แต่ต้องเข้าใจ CSS ที่อยู่ข้างใน

  • ติดตั้งด้วย CDN: CSS ใน head, JS bundle ท้าย body
  • .container / .container-fluid → .row → .col-*
  • 12 คอลัมน์ + Breakpoint sm md lg xl xxl แบบ Mobile-First
  • ฟอร์ม: form-control, form-label · ตรวจด้วย .was-validated
  • คอมโพเนนต์ + Utility Classes · ตรวจโค้ดจาก AI ว่าเป็น v5
