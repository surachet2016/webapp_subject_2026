7.12.2 การเข้ารหัสรหัสผ่านที่ปลอดภัย (Secure Password Hashing)

ห้ามเก็บรหัสผ่านตรง ๆ หรือด้วย md5

$hash = password_hash($pass, PASSWORD_DEFAULT); // บันทึก $hash ลงฐานข้อมูล if (password_verify($input, $hash)) { // รหัสผ่านถูกต้อง }

❌ เก็บตรง ๆ

❌ md5 ได้ค่าเดิมทุกครั้ง ถอดด้วยตารางสำเร็จรูปได้

✓ password_hash ใส่ salt สุ่ม ได้ค่าต่างกันทุกครั้ง

ค่าในกล่องสีเหลืองเป็นตัวอย่างรูปแบบ bcrypt ที่สุ่มขึ้นในเบราว์เซอร์เพื่อประกอบการสอน ไม่ใช่ผลจาก PHP จริง

7.13 AI-Assisted PHP Development (OWASP, 2023d; The PHP Group, 2024b)

สั่งให้ตรวจตามหัวข้อ แล้วทดสอบเองทุกครั้ง

บทบาท: ผู้ตรวจสอบความปลอดภัย PHP 8.x งาน: ตรวจโค้ด login.php ด้านล่าง หัวข้อที่ต้องตรวจ: 1) SQL Injection (ใช้ prepared statement หรือไม่) 2) การเก็บและตรวจรหัสผ่าน (password_hash/verify) 3) XSS (htmlspecialchars ทุกจุดที่ echo) 4) Session fixation และค่าคุกกี้ 5) การแสดง error ให้ผู้ใช้เห็น ผลลัพธ์: ตาราง บรรทัด / ช่องโหว่ / ระดับความเสี่ยง / โค้ดที่แก้ [วางโค้ด ห้ามวางรหัสผ่านฐานข้อมูลจริง]
