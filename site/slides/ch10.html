เรียนจบบทนี้ นักศึกษาจะ...

  • เลือกโดเมนและโฮสติ้งให้เหมาะกับเว็บไซต์
  • อัปโหลดไฟล์และย้ายฐานข้อมูลขึ้นเซิร์ฟเวอร์จริง
  • เปิด HTTPS และตั้งค่า DNS ได้
  • เข้าใจการนำส่งอัตโนมัติด้วย CI/CD
  • ตรวจประสิทธิภาพ ความปลอดภัย และนำเสนอผลงาน

ผลลัพธ์การเรียนรู้ (CLO) ของบทนี้

CLO2 วิเคราะห์ความต้องการและจัดทำขอบเขตงานเว็บไซต์ · CLO3 ใช้เครื่องมือพัฒนา จัดตั้ง และบริหารเว็บไซต์

CLO4 สร้างเว็บเพจที่มีปฏิสัมพันธ์ · CLO5 ประยุกต์แก้ปัญหา ทดสอบ และปรับปรุง

CLO6 อ้างอิงแหล่งที่มา เคารพสิทธิ และรับผิดชอบต่องาน

CLO7 ทำงานร่วมกับผู้อื่นตามบทบาท และนำเสนอแนวคิด ขั้นตอนการพัฒนา และผลการดำเนินงานของเว็บไซต์ได้ชัดเจน

ใบงานที่ 10: จัดตั้งเว็บไซต์บนเซิร์ฟเวอร์จริง ติดตั้ง HTTPS และตรวจสอบประสิทธิภาพ

10.1 การจดทะเบียนโดเมนเนม (ICANN, 2024)

อ่านที่อยู่เว็บทีละส่วน

https://www.mysite.ac.th/menu/latte

คลิกส่วนของที่อยู่เว็บ

จดโดเมน

  • ตรวจชื่อว่างกับผู้รับจดทะเบียน (Registrar)
  • .th, .ac.th, .co.th จดผ่านผู้ให้บริการที่ THNIC รับรอง และต้องมีเอกสารตามประเภท
  • ต่ออายุทุกปี ถ้าลืมอาจเสียชื่อโดเมน

10.2 การติดตั้งเว็บโฮสติ้ง · วิธีเลือกโฮสต์เว็บใน 4 ขั้นตอน

ติ๊กความต้องการ แล้วดูว่าโฮสต์แบบไหนเหมาะ

ขั้นตอน: วิเคราะห์ความต้องการ → ดูแพ็กเกจ → ค้นคว้ารีวิว → เปรียบเทียบปัจจัยหลัก

Shared Hosting

หลายเว็บใช้เครื่องเดียวกัน ราคาถูก มี cPanel/DirectAdmin และ PHP/MySQL พร้อม

VPS

เครื่องเสมือนของเราเอง ติดตั้งได้อิสระ ต้องดูแลระบบและความปลอดภัยเอง

Cloud Platform

ขยายตามผู้ใช้ได้ คิดเงินตามการใช้งาน ต้องมีความรู้ด้านระบบมากขึ้น

Static Hosting

เช่น GitHub Pages ฟรี เร็ว แต่รัน PHP และฐานข้อมูลไม่ได้

10.3 การอัปโหลดเว็บไซต์ขึ้นสู่ Server ด้วยโปรแกรม FileZilla

คลิกไฟล์ทางซ้าย เพื่อส่งขึ้นเซิร์ฟเวอร์

โฮสต์ mysite.ac.thจำลอง
เครื่องเรา: C:\xampp\htdocs\mysite\
เซิร์ฟเวอร์: /public_html/

10.3.1 การส่งออกและนำเข้าฐานข้อมูล (.sql) เพื่อย้ายขึ้นโฮสติ้ง

ย้ายข้อมูลจาก localhost ขึ้นโฮสต์

ห้ามใช้ root ที่ไม่มีรหัสผ่านบนเซิร์ฟเวอร์จริง และอย่าอัปโหลดไฟล์ .sql ที่มีข้อมูลส่วนบุคคลไว้ในโฟลเดอร์สาธารณะ

10.3.2 การเผยแพร่เว็บไซต์แบบสถิตด้วย GitHub Pages

เว็บ HTML/CSS/JS ขึ้นออนไลน์ฟรี

  1. สร้าง Repository บน GitHub (บทที่ 2)
  2. push ไฟล์ โดยมี index.html อยู่ที่ราก
  3. Settings › Pages › เลือก branch main
  4. รอสักครู่ เปิด https://ชื่อผู้ใช้.github.io/ชื่อ-repo/
  5. ผูกโดเมนตัวเองได้ และมี HTTPS ให้

ข้อจำกัด

  • รัน PHP และฐานข้อมูลไม่ได้ (งานบทที่ 7–9 ต้องใช้โฮสต์ที่รองรับ)
  • Repository สาธารณะ ทุกคนเห็นโค้ด ห้ามใส่รหัสผ่านหรือข้อมูลส่วนบุคคล
  • เหมาะกับพอร์ตโฟลิโอ เว็บประวัติ เอกสารรายวิชา

10.4 HTTPS และใบรับรองอิเล็กทรอนิกส์ (Cloudflare, 2024; OWASP, 2023f)

ก่อนส่งข้อมูล เบราว์เซอร์กับเซิร์ฟเวอร์ "จับมือ" กันก่อน

1. เบราว์เซอร์: สวัสดี ฉันรองรับ TLS 1.3 และวิธีเข้ารหัสเหล่านี้
2. เซิร์ฟเวอร์: ตกลงใช้วิธีนี้ นี่คือใบรับรองของ mysite.ac.th
3. เบราว์เซอร์: ตรวจใบรับรองกับผู้ออก (CA) ที่เชื่อถือ ชื่อตรง ยังไม่หมดอายุ ✓
4. ทั้งสองฝ่ายสร้างกุญแจลับร่วมกัน (Key Exchange)
5. 🔒 ส่ง HTTP ทั้งหมดผ่านช่องทางเข้ารหัส

ถ้าใบรับรองหมดอายุ หรือชื่อโดเมนไม่ตรง เบราว์เซอร์จะขึ้นหน้าเตือน "การเชื่อมต่อนี้ไม่เป็นส่วนตัว" ผู้ใช้ส่วนใหญ่จะออกจากเว็บทันที

ทบทวนพื้นฐาน HTTP/HTTPS ในบทที่ 2 หัวข้อ 2.8.1

10.4.1 การติดตั้งใบรับรองความปลอดภัยฟรี (ISRG, 2024; Cloudflare, 2024)

ใบรับรองฟรี อายุสั้น ต่ออายุอัตโนมัติ

สองทางที่นิยม

  • Let's Encrypt ผ่าน AutoSSL ของ cPanel หรือ certbot บน VPS ต่ออายุให้อัตโนมัติ
  • Cloudflare ชี้ DNS ผ่าน Cloudflare ได้ HTTPS และ CDN ควรตั้งโหมด Full (strict) ให้ช่วงระหว่าง Cloudflare กับเซิร์ฟเวอร์เข้ารหัสด้วย
  • ตั้ง redirect HTTP → HTTPS ทั้งเว็บ (10.6.4)
