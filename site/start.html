ก่อนเริ่มเรียน

เริ่มต้นใช้งาน: เตรียมเครื่องมือ

ทำตามลำดับนี้ครั้งเดียวก็พร้อมเรียนทั้งเทอม ใช้ได้ทั้ง Windows และ macOS

1. โปรแกรมแก้ไขโค้ด

ติดตั้ง Visual Studio Code จาก code.visualstudio.com แล้วเพิ่มส่วนขยาย Live Server และ Prettier

2. เว็บเซิร์ฟเวอร์จำลองในเครื่อง (PHP + MySQL)

  • Windows: ติดตั้ง XAMPP จาก apachefriends.org เปิดบริการ Apache และ MySQL ใน XAMPP Control Panel แล้วเปิด http://localhost ไฟล์เว็บวางในโฟลเดอร์ htdocs
  • macOS: ติดตั้ง MAMP (ฟรี) จาก mamp.info เปิด Apache 8888 และ MySQL 8889 (ค่าเริ่มต้น รหัส root / root สำหรับเครื่องของตนเองเท่านั้น) ไฟล์เว็บวางใน /Applications/MAMP/htdocs แล้วเปิด http://localhost:8888
รหัสผ่านค่าเริ่มต้นนี้ใช้ได้เฉพาะเครื่องของตนเองเพื่อการเรียนเท่านั้น ห้ามใช้รหัสผ่านเดียวกันกับเซิร์ฟเวอร์จริง

3. Git และ GitHub (แนะนำ)

ติดตั้ง Git จาก git-scm.com สมัคร GitHub ด้วยบัญชีของตนเอง แล้วใช้คำสั่งพื้นฐาน git init, git add ., git commit -m "ข้อความ" ตามหัวข้อในบทที่ 2

4. อัปโหลดเว็บขึ้นเซิร์ฟเวอร์ของรายวิชา

อาจารย์จะแจ้งชื่อผู้ใช้และรหัสผ่านเป็นรายบุคคล ห้ามนำไปโพสต์ที่ใด และห้ามให้ผู้อื่นใช้

  1. ต่อ Wi-Fi หรือ VPN ของมหาวิทยาลัย (ต่อจากภายนอกจะเชื่อมไม่ติด)
  2. ติดตั้ง FileZilla เปิดแถบ Quickconnect แล้วกรอก Host เป็น sftp://fms.pnu.ac.th ใส่ชื่อผู้ใช้ รหัสผ่าน และ Port 22
  3. เมื่อเชื่อมต่อสำเร็จ จะเห็นโฟลเดอร์ htdocs ฝั่งขวา อัปโหลดไฟล์เข้าโฟลเดอร์นี้เท่านั้น ต้องมี index.php หรือ index.html
  4. เปิดเว็บของตนเองที่ https://fms.pnu.ac.th/course/ชื่อผู้ใช้/
  5. แก้ไฟล์แล้วอัปโหลดทับ รีเฟรชด้วย Ctrl+F5 (Mac: Cmd+Shift+R)

เชื่อมต่อฐานข้อมูลด้วย mysqli

ฐานข้อมูลและชื่อผู้ใช้ MySQL ของแต่ละคนอาจารย์จะแจ้งให้ (ชื่อขึ้นต้นด้วย course_) ใช้ host localhost ตัวอย่างโค้ดใช้ try/catch เพราะ PHP 8.1 ขึ้นไปจะโยน exception เมื่อเชื่อมต่อไม่ได้

PHP
<?php
mysqli_report(MYSQLI_REPORT_ERROR | MYSQLI_REPORT_STRICT);
try {
    $conn = new mysqli('localhost', 'course_ชื่อผู้ใช้', 'รหัสผ่านของฉัน', 'course_ชื่อผู้ใช้');
    $conn->set_charset('utf8mb4');
    echo 'เชื่อมต่อฐานข้อมูลสำเร็จ';
} catch (mysqli_sql_exception $e) {
    error_log($e->getMessage());
    echo 'เชื่อมต่อฐานข้อมูลไม่สำเร็จ';
}

อย่าเขียนรหัสผ่านจริงลงในไฟล์ที่นำขึ้น GitHub หรือส่งใน Google Classroom

5. แก้ปัญหาที่พบบ่อย

ปัญหาวิธีแก้
ต่อ SFTP ไม่ได้ (Connection timed out)ยังไม่ได้ต่อ Wi-Fi หรือ VPN ของมหาวิทยาลัย
Permission denied ตอนอัปโหลดต้องอัปโหลดในโฟลเดอร์ htdocs เท่านั้น
เปิดเว็บแล้ว 404ตรวจ URL ให้ตรงชื่อผู้ใช้ และมี index.php หรือ index.html ใน htdocs
หน้าจอขาวมักเป็น error ใน PHP (syntax ผิด) ให้แจ้งอาจารย์ตรวจ log
เชื่อมต่อฐานข้อมูลไม่สำเร็จตรวจชื่อผู้ใช้ รหัสผ่าน ชื่อฐานข้อมูล (มักลืม course_ นำหน้า)
อัปโหลดแล้วเว็บไม่เปลี่ยนเบราว์เซอร์จำหน้าเก่า กด Ctrl+F5 หรือเปิดโหมดส่วนตัว

กติกาการใช้งานเซิร์ฟเวอร์

  • ห้ามเปิดเผยหรือแชร์รหัสผ่านของตนเอง
  • ห้ามพยายามเข้าถึงไฟล์หรือฐานข้อมูลของผู้อื่น
  • อัปโหลดเฉพาะงานของรายวิชานี้
