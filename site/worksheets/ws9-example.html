ตัวอย่างการทำใบงานที่ 9

เว็บไซต์ร้านไร่ภูคำด้วย WordPress: ติดตั้ง สร้างหน้า ปลั๊กอิน และ SEO

ตัวอย่างนี้สร้างเว็บไซต์ของร้านสมมติ "ไร่ภูคำ" ด้วย WordPress ภาษาไทยบนเครื่องของตนเอง ต่อจาก Sitemap ในใบงานที่ 1 หน้านี้เป็นขั้นตอนและค่าที่ต้องตั้ง ยังไม่มีภาพหน้าจอจากการติดตั้งจริง ชื่อเมนูภาษาไทยอาจต่างไปตามรุ่นของ WordPress และคำแปล จึงเขียนชื่อภาษาอังกฤษกำกับไว้

สิ่งที่ต้องมี

  • เซิร์ฟเวอร์XAMPP หรือ MAMP ที่ Start ทั้ง Apache และ MySQL (ใบงานที่ 2)
  • ฐานข้อมูลphpMyAdmin (ใบงานที่ 8)
  • เนื้อหาSitemap และ CI จากใบงานที่ 1

9.1

ติดตั้งและตั้งค่า WordPress

1. ดาวน์โหลดและสร้างฐานข้อมูล

  1. ดาวน์โหลดรุ่นภาษาไทยจาก th.wordpress.org/download (แหล่งทางการเท่านั้น) แตกไฟล์ แล้วเปลี่ยนชื่อโฟลเดอร์ wordpress เป็น phukham-wp วางใน htdocs
  2. เปิด phpMyAdmin แท็บ Databases สร้างฐานข้อมูลชื่อ phukham_wp เลือก Collation utf8mb4_unicode_ci (ไม่ต้องสร้างตาราง WordPress สร้างให้เอง)
  3. เปิด http://localhost/phukham-wp (MAMP: http://localhost:8888/phukham-wp) จะเข้าหน้าติดตั้ง กรอกค่าตามตาราง
ช่องในหน้าติดตั้งค่าที่กรอกหมายเหตุ
ชื่อฐานข้อมูล (Database Name)phukham_wpตรงกับที่สร้างใน phpMyAdmin
ชื่อผู้ใช้ (Username)rootค่าเริ่มต้นของ XAMPP และ MAMP บนเครื่องตนเอง บนเซิร์ฟเวอร์จริงต้องใช้ผู้ใช้เฉพาะเว็บไซต์
รหัสผ่าน (Password)XAMPP: เว้นว่าง · MAMP: rootตามภาคผนวก ค เหมือนใบงานที่ 8
โฮสต์ฐานข้อมูล (Database Host)localhostไม่ต้องใส่พอร์ต
คำนำหน้าตาราง (Table Prefix)pk_เปลี่ยนจาก wp_ ค่าเริ่มต้น ทำให้เดาชื่อตารางยากขึ้นเล็กน้อย
ชื่อเว็บไซต์ / ชื่อผู้ใช้ผู้ดูแลไร่ภูคำ Coffee Roasters / ชื่อที่ไม่ใช่ adminห้ามใช้ admin เพราะเป็นชื่อแรกที่ผู้โจมตีลองเดา
รหัสผ่านผู้ดูแลรหัสผ่านที่ WordPress สุ่มให้ หรือยาวอย่างน้อย 12 ตัวจดไว้ในที่ปลอดภัย

2. ตั้งค่าทั่วไป (Settings › General)

ช่องค่าที่ตั้งเหตุผล
ชื่อเว็บไซต์ (Site Title)ไร่ภูคำ Coffee Roastersแสดงในแท็บเบราว์เซอร์และผลการค้นหา
คำโปรย (Tagline)กาแฟคั่วสดจากไร่บนดอยเชียงรายบอกว่าเว็บไซต์เกี่ยวกับอะไร อย่าปล่อยเป็นค่าเริ่มต้น
ภาษาของเว็บไซต์ (Site Language)ไทยกำหนด lang="th" ให้หน้าเว็บ
เขตเวลา (Timezone)กรุงเทพ (UTC+7)เวลาเผยแพร่บทความถูกต้อง
รูปแบบวันที่j F Yแสดงเป็น 19 พฤศจิกายน 2026
อีเมลผู้ดูแลอีเมลที่ใช้งานจริงรับแจ้งเตือนความปลอดภัยและแบบฟอร์มติดต่อ

ที่ Settings › Reading ช่อง "ขอให้เครื่องมือค้นหาไม่ทำดัชนีเว็บไซต์นี้" (Discourage search engines) ติ๊กไว้ได้ระหว่างพัฒนา แต่ต้องเอาออกเมื่อเปิดเว็บจริง ไม่อย่างนั้นเว็บจะไม่ขึ้นในผลการค้นหา

3. ลิงก์ถาวร (Settings › Permalinks) ตามหัวข้อ 9.2.1

รูปแบบตัวอย่าง URL
ค่าเริ่มต้น (Plain)/phukham-wp/?page_id=7อ่านไม่ออกว่าเป็นหน้าอะไร
ชื่อเรื่อง (Post name) ✅/phukham-wp/workshop/อ่านรู้เรื่อง มีคำสำคัญใน URL
  1. เลือก Post name แล้วกดบันทึก WordPress จะเขียนไฟล์ .htaccess ให้เอง
  2. ตั้งค่านี้ก่อนสร้างเนื้อหา เพราะเปลี่ยนภายหลังแล้วลิงก์เดิมที่แชร์ไปจะใช้ไม่ได้
  3. ตั้ง slug ของหน้าเป็นภาษาอังกฤษสั้น ๆ เช่น workshop contact ถ้าใช้ชื่อภาษาไทย URL จะถูกแปลงเป็นรหัสยาว ๆ เช่น %e0%b8%95%e0%b8%b4… เมื่อคัดลอกไปแชร์
ข้อผิดพลาดที่พบบ่อย

Error establishing a database connection

ภาพหน้าจอที่ต้องแนบ
  • หน้าติดตั้งที่กรอกค่าฐานข้อมูล
  • หน้า Settings › General
  • หน้า Settings › Permalinks ที่เลือก Post name
  • หน้าเว็บที่เปิดด้วย URL แบบชื่อเรื่องได้
9.2

สร้างหน้าเว็บด้วย Block Editor

สร้าง 3 หน้าที่ Pages › Add New Page แล้วตั้งหน้าหลักที่ Settings › Reading › "หน้าแรกแสดง" เลือก "หน้าคงที่" (A static page) เป็นหน้าหลัก

วิธีเพิ่มบล็อกที่ใช้บ่อย

  • พิมพ์ / ในบรรทัดว่าง แล้วพิมพ์ชื่อบล็อก เช่น /cover /columns
  • กดปุ่ม + มุมซ้ายบน แท็บ Blocks / Patterns / Media
  • เปิด List View (ไอคอนสามขีด) เพื่อดูว่าบล็อกไหนซ้อนอยู่ในบล็อกไหน
  • แถบด้านขวา (Settings) ใช้ตั้งสี ระยะห่าง และ Alt Text ของรูป

คำศัพท์

  • Block ชิ้นเนื้อหา 1 ชิ้น เช่น ย่อหน้า รูป ปุ่ม
  • Columns แบ่งเนื้อหาเป็นคอลัมน์ บนมือถือเรียงลงเป็นแถวเดียวให้เอง (เมื่อเปิด Stack on mobile)
  • Cover รูปหรือวิดีโอพื้นหลังพร้อมข้อความทับ ใช้ทำ Hero
  • Block Pattern ชุดบล็อกสำเร็จรูปที่ธีมเตรียมไว้ เช่น Call to action, Pricing

9.3

ธีมและปลั๊กอิน

เลือกธีม (Appearance › Themes › Add New Theme)

เกณฑ์ตรวจที่ไหน
มาจากคลังทางการ wordpress.org/themesติดตั้งผ่านหน้า Add New Theme เท่านั้น ห้ามใช้ธีมเสียเงินที่แจกฟรีจากเว็บอื่น (มักฝังโค้ดอันตราย และผิดเงื่อนไขของผู้ขาย)
Responsive และรองรับ Block Editorป้าย Block Editing / Full Site Editing ในรายละเอียดธีม หรือเปิด Live Preview แล้วย่อจอ
อัปเดตล่าสุดไม่เกิน 6 เดือนLast updated ในหน้าธีม
ใช้งานจริงจำนวนมากActive installations
ใบอนุญาตเข้ากันได้กับ GPLทุกธีมในคลังทางการผ่านข้อนี้ (หัวข้อ 9.4.2)

ตัวอย่างนี้ใช้ธีมเริ่มต้นของ WordPress ตระกูล Twenty Twenty-X รุ่นล่าสุดที่มากับการติดตั้ง ซึ่งเป็น Block Theme และ Responsive จึงแก้ Header, Footer และสีทั้งเว็บได้ใน Appearance › Editor › Styles ตามแนวคิด Full Site Editing ในหัวข้อ 9.3.2 ตั้งสีหลักเป็น #1F4D3A และสีปุ่มเป็น #B3362B ตาม CI

9.4

ใช้ AI ช่วยเขียนเนื้อหาและทำ SEO

Prompt ด้านล่างดัดแปลงจากกรอบคำสั่งในหัวข้อ 9.5.3 จุดที่เพิ่มคือให้ข้อมูลจริงของร้านไปด้วย และห้าม AI แต่งข้อมูลเพิ่ม เพราะ AI มักเติมรางวัล ตัวเลข หรือคำรับรองจากลูกค้าที่ไม่มีจริงลงในบทความประชาสัมพันธ์

Prompt 1: บทความประชาสัมพันธ์

โค้ด
Role: SEO Content Strategist ที่เขียนภาษาไทยเป็นธรรมชาติ
Task: เขียนบทความประชาสัมพันธ์ภาษาไทย ยาวประมาณ 600 คำ สำหรับเว็บไซต์ร้าน "ไร่ภูคำ Coffee Roasters"
หัวข้อ: เปิดรับสมัครเวิร์กช็อปดริปกาแฟสำหรับมือใหม่ รอบเดือนธันวาคม

ข้อมูลจริงที่ต้องใช้ (ห้ามแต่งข้อมูลเพิ่ม):
- เวิร์กช็อป 3 ชั่วโมง รอบเสาร์และอาทิตย์ 09:00–12:00 รับรอบละ 8 คน
- ราคา 1,290 บาท รวมอุปกรณ์ เมล็ดกาแฟ 100 g กลับบ้าน
- สอนเลือกเมล็ด บด ชั่ง และดริปด้วยดริปเปอร์เซรามิก
- สมัครผ่านหน้า "ติดต่อเรา" ของเว็บไซต์

Constraints:
- กลุ่มผู้อ่าน: คนทำงานอายุ 22–40 ปีที่อยากชงกาแฟเองที่บ้าน
- Focus Keyword: "เวิร์กช็อปดริปกาแฟ" ใช้ในย่อหน้าแรก และหัวข้อ H2 อย่างน้อย 1 หัวข้อ
- โครงสร้างหัวข้อ H2/H3 ที่ชัดเจน ย่อหน้าสั้น ปิดท้ายด้วยข้อความชวนสมัคร
- ห้ามอ้างรางวัล ใบรับรอง หรือคำรับรองจากลูกค้าที่ไม่มีในข้อมูลข้างต้น
Output: บทความ + Meta Title (ไม่เกิน 60 ตัวอักษร) + Meta Description (ไม่เกิน 160 ตัวอักษร) + slug ภาษาอังกฤษ

Prompt 2: Alt Text (แนบรูปไปด้วย)

โค้ด
เขียนข้อความ Alt Text ภาษาไทยสำหรับรูปที่แนบมา ใช้ในหน้า "เวิร์กช็อปดริปกาแฟ" ของร้านกาแฟ
- อธิบายสิ่งที่เห็นในรูปจริง ไม่เกิน 125 ตัวอักษร
- ไม่ขึ้นต้นด้วย "รูปภาพของ" หรือ "ภาพที่แสดง"
- ใส่ Focus Keyword ได้เฉพาะเมื่อตรงกับสิ่งที่อยู่ในรูป ห้ามยัดคำ
- ถ้าเป็นภาพตกแต่งที่ไม่มีข้อมูล ให้ตอบว่า "ควรเว้นว่าง (alt="")"

Prompt 3: Meta Title / Description

โค้ด
ช่วยเขียน Meta Title และ Meta Description ภาษาไทยให้หน้าเว็บต่อไปนี้ อย่างละ 3 ตัวเลือก
- Meta Title ไม่เกิน 60 ตัวอักษร ขึ้นต้นด้วยคำสำคัญ ปิดท้ายด้วย "| ไร่ภูคำ"
- Meta Description 120–160 ตัวอักษร บอกว่าผู้อ่านจะได้อะไร และมีคำชวนให้คลิก
- ใช้เฉพาะข้อมูลในเนื้อหาด้านล่าง ระบุจำนวนตัวอักษรของแต่ละตัวเลือก

ใส่ค่า SEO ใน WordPress

  1. เปิดหน้าใน Editor เลื่อนลงไปที่กล่อง Yoast SEO ใต้เนื้อหา (หรือไอคอน Yoast ที่แถบด้านขวา)
  2. ใส่ Focus keyphrase, SEO title, Slug และ Meta description แล้วดูตัวอย่างการแสดงผลใน Google preview
  3. ใส่ Alt Text ที่บล็อก Image › แถบด้านขวา › Alternative text
  4. บันทึก เปิดหน้าเว็บ กด Ctrl+U (View Source) ค้นหา <title> และ <meta name="description" เพื่อยืนยันว่าค่าที่ตั้งออกมาในหน้าเว็บจริง

ตรวจทำไม
ตัวเลข ราคา วันเวลา ตรงกับข้อมูลจริงAI อาจคำนวณหรือจำข้อมูลผิด (Hallucination) ตามหัวข้อ 9.5.2
ไม่มีรางวัล ใบรับรอง หรือคำรับรองจากลูกค้าที่แต่งขึ้นเป็นการโฆษณาเกินจริงและทำลายความน่าเชื่อถือของร้าน
ภาษาไทยเป็นธรรมชาติ ไม่ใช่ภาษาแปลอ่านออกเสียงดู ตัดคำฟุ่มเฟือย
Alt Text ตรงกับรูปจริงถ้าไม่ได้แนบรูปให้ AI ดู มันจะเดาเนื้อหาของรูปเอง
ไม่ยัด Keyword ซ้ำ ๆSearch Engine ลดอันดับเนื้อหาที่เขียนเพื่อเครื่องมากกว่าเพื่อคน
