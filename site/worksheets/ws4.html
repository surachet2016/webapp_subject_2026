ใบงานที่ 4

การตกแต่งหน้าเว็บด้วย CSS Box Model, Modern Units, Flexbox และ Grid

ผลการเรียนรู้ที่คาดหวัง (CLO): CLO 3 (ควบคุมรูปแบบการแสดงผลและเลย์เอาต์ด้วย CSS) และ CLO 5 (ประยุกต์สร้างเว็บแบบ Responsive ตามโจทย์)

เครื่องมือและซอฟต์แวร์ที่ใช้: Visual Studio Code, CSS3, Chrome DevTools

คำสั่งและขั้นตอนการปฏิบัติงาน

การแบ่งส่วนของใบงาน (ตรงกับแผนการสอนรายสัปดาห์ใน มคอ.3): ส่วนที่ 1 สัปดาห์ที่ 5 ทำข้อ 4.0; ส่วนที่ 2 สัปดาห์ที่ 6 ทำข้อ 4.1–4.4 ส่งใบงานฉบับสมบูรณ์ทั้งสองส่วนผ่าน Google Classroom ภายในสัปดาห์ที่ 6 และประเมินด้วยแบบประเมินรูบริกฉบับเดียว

  • 4.0 การกำหนดรูปแบบด้วย CSS พื้นฐาน (ส่วนที่ 1): ใช้ Element Selector, Class Selector และ ID Selector กำหนดสี พื้นหลัง และแบบอักษร จากนั้นทดลองปรับ Content, Padding, Border และ Margin ของกล่องข้อความ แล้วสังเกตผลด้วยเครื่องมือพัฒนาในเว็บเบราว์เซอร์ (DevTools)
  • 4.1 การประกาศตัวแปรและการกำหนดสไตล์ส่วนกลาง: ประกาศ CSS Custom Properties (:root) สำหรับชุดสี ฟอนต์ และขนาดขอบมน เพื่อใช้ซ้ำในไฟล์ style.css
  • 4.2 การจัดเลย์เอาต์ด้วย CSS Flexbox: สร้างแถบนำทาง (Navbar) ที่มีโลโก้ด้านซ้ายและเมนูด้านขวา (justify-content: space-between) และการ์ดแสดงคุณสมบัติ 3 คอลัมน์ที่ยืดหยุ่นได้
  • 4.3 การจัดเลย์เอาต์ตาราง 2 มิติด้วย CSS Grid: สร้างแกลเลอรีรูปภาพหรือหน้ารายการสินค้าด้วย CSS Grid (grid-template-columns: repeat(auto-fit, minmax(250px, 1fr))) พร้อมกำหนดช่องว่างด้วย gap
  • 4.4 การออกแบบ Responsive ด้วย Media Queries: กำหนดจุดตัดหน้าจอ (@media min-width: 768px) เพื่อให้หน้าเว็บเปลี่ยนการแสดงผลจาก 1 คอลัมน์บนมือถือ สู่หลายคอลัมน์บนจอคอมพิวเตอร์อย่างราบรื่น

การแปลงคะแนน: คะแนนถ่วงน้ำหนักจากแบบประเมินรูบริก (เต็ม 20) ÷ 20 = คะแนนเก็บของใบงานนี้ (เต็ม 1 คะแนน) ใบงาน 10 ชุดรวมเป็น 10 คะแนนตาม มคอ.3

เกณฑ์การส่งมอบงานและการประเมินผล: บันทึกภาพหน้าจอผลลัพธ์การทำงานพร้อมแนบซอร์สโค้ด และส่งผ่านระบบบริหารการเรียนรู้ (LMS) ภายในระยะเวลาที่กำหนด โดยจะประเมินผลตามเกณฑ์รูบริกการประเมินใบงาน

การส่งงาน ส่งผ่าน Google Classroom ตามกำหนดของอาจารย์ ตั้งชื่อไฟล์ตามรูปแบบ รหัสนักศึกษา_ใบงานที่4
