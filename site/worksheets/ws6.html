ใบงานที่ 6

การเขียนโปรแกรมเชิงปฏิสัมพันธ์ด้วย Modern JavaScript (ES6+) และการควบคุม DOM

ผลการเรียนรู้ที่คาดหวัง (CLO): CLO 4 (สร้างเว็บเพจที่มีปฏิสัมพันธ์ด้วย JavaScript) และ CLO 5 (ประยุกต์แก้ปัญหาตามโจทย์)

เครื่องมือและซอฟต์แวร์ที่ใช้: Visual Studio Code, เบราว์เซอร์ Developer Console

คำสั่งและขั้นตอนการปฏิบัติงาน

การแบ่งส่วนของใบงาน (ตรงกับแผนการสอนรายสัปดาห์ใน มคอ.3): ส่วนที่ 1 สัปดาห์ที่ 10 ทำข้อ 6.1–6.3; ส่วนที่ 2 สัปดาห์ที่ 11 ทำข้อ 6.4 ส่งใบงานฉบับสมบูรณ์ทั้งสองส่วนผ่าน Google Classroom ภายในสัปดาห์ที่ 11 และประเมินด้วยแบบประเมินรูบริกฉบับเดียว

  • 6.1 การควบคุมองค์ประกอบ DOM และ Event Handling: เขียนฟังก์ชันคำนวณราคาสินค้าและภาษีมูลค่าเพิ่มแบบเรียลไทม์ (ดูหัวข้อ 6.8.4) โดยดักจับเหตุการณ์ input หรือ change ผ่าน addEventListener
  • 6.2 การตรวจสอบความถูกต้องของฟอร์มฝั่ง Client (Client-Side Validation): เขียนคำสั่งตรวจสอบรหัสผ่านตรงกัน และตรวจสอบความถูกต้องของอีเมลด้วย Regular Expression ก่อนส่งข้อมูล
  • 6.3 การสร้างลูกเล่นและการโต้ตอบทางสายตา: เขียนโปรแกรมสลับโหมด Dark Mode / Light Mode โดยการสลับคลาสของแท็ก <body> ผ่าน JavaScript classList.toggle (ดูหัวข้อ 6.8.4)
  • 6.4 การเชื่อมต่อข้อมูลแบบอะซิงโครนัสด้วย Fetch API: เขียนฟังก์ชัน async/await ดึงข้อมูลจำลองรูปแบบ JSON จากภายนอก (เช่น JSONPlaceholder API ดูหัวข้อ 6.9.1) แล้วนำมาเรนเดอร์ลงในตารางหรือการ์ด HTML

การแปลงคะแนน: คะแนนถ่วงน้ำหนักจากแบบประเมินรูบริก (เต็ม 20) ÷ 20 = คะแนนเก็บของใบงานนี้ (เต็ม 1 คะแนน) ใบงาน 10 ชุดรวมเป็น 10 คะแนนตาม มคอ.3

เกณฑ์การส่งมอบงานและการประเมินผล: บันทึกภาพหน้าจอผลลัพธ์การทำงานพร้อมแนบซอร์สโค้ด และส่งผ่านระบบบริหารการเรียนรู้ (LMS) ภายในระยะเวลาที่กำหนด โดยจะประเมินผลตามเกณฑ์รูบริกการประเมินใบงาน

การส่งงาน ส่งผ่าน Google Classroom ตามกำหนดของอาจารย์ ตั้งชื่อไฟล์ตามรูปแบบ รหัสนักศึกษา_ใบงานที่6
