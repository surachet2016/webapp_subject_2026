2.1

ติดตั้งและปรับแต่ง VS Code

  1. ดาวน์โหลดจาก code.visualstudio.com แล้วติดตั้ง บน Windows ให้ติ๊ก Add "Open with Code" action และ Add to PATH ไว้ด้วย
  2. เปิดแท็บ Extensions (Ctrl+Shift+X / Cmd+Shift+X) ค้นหาและติดตั้งทีละตัว ตรวจชื่อผู้พัฒนาให้ตรงตามตาราง เพราะมีส่วนขยายชื่อคล้ายกันหลายตัว
  3. ตั้ง Prettier เป็นตัวจัดรูปแบบหลักและให้จัดอัตโนมัติเมื่อบันทึก: กด Ctrl+Shift+P พิมพ์ Preferences: Open User Settings (JSON) แล้วเพิ่มค่าด้านล่าง

2.2

ติดตั้งสภาพแวดล้อมจำลอง (XAMPP / MAMP)

Windows: XAMPP

  1. ดาวน์โหลดจาก apachefriends.org ติดตั้งที่ C:\xampp (ค่าเริ่มต้น) เลือกอย่างน้อย Apache, MySQL, PHP และ phpMyAdmin
  2. เปิด XAMPP Control Panel กด Start ที่ Apache และ MySQL จนชื่อโมดูลเป็นสีเขียว ถ้า Windows Firewall ถาม ให้อนุญาตเฉพาะเครือข่ายส่วนตัว
  3. เปิด http://localhost จะถูกพาไปหน้า Dashboard ของ XAMPP
  4. วางไฟล์เว็บใน C:\xampp\htdocs

macOS: MAMP (ตามภาคผนวก ค)

  1. ดาวน์โหลดรุ่นฟรีจาก mamp.info แล้วลากลง Applications
  2. เปิด MAMP กด Start ไฟของ Apache และ MySQL ต้องเป็นสีเขียว พอร์ตเริ่มต้นคือ Apache 8888 และ MySQL 8889
  3. กด WebStart หรือเปิด http://localhost:8888
  4. วางไฟล์เว็บใน /Applications/MAMP/htdocs รหัส MySQL เริ่มต้น root / root ใช้ได้กับเครื่องตนเองเท่านั้น

ภาพจำลอง หมายเลข PID ในเครื่องจริงจะต่างไป สิ่งที่ต้องดูคือชื่อ Apache และ MySQL เป็นพื้นสีเขียว และมีพอร์ตแสดง

ทดสอบว่า Apache ประมวลผล PHP ได้: สร้างไฟล์ htdocs/test/info.php แล้วเปิด http://localhost/test/info.php (MAMP: http://localhost:8888/test/info.php) ต้องเห็นหัวข้อและเลขเวอร์ชัน PHP ไม่ใช่เห็นโค้ด PHP ดิบ

โค้ด
<?php
echo "<h1>Apache + PHP ทำงานแล้ว</h1>";
echo "PHP version: " . phpversion();
ภาพหน้าจอที่ต้องแนบ
  • XAMPP Control Panel หรือหน้าต่าง MAMP ที่ Apache และ MySQL เป็นสีเขียว
  • หน้า Dashboard ที่ http://localhost (หรือ WebStart ของ MAMP)
  • หน้า info.php ที่แสดงเวอร์ชัน PHP
ปัญหาที่พบบ่อยและวิธีแก้
Apache กด Start แล้วดับทันที / Port 80 in use
มีโปรแกรมอื่นใช้พอร์ต 80 อยู่ (เช่น IIS หรือ VMware) ปิดโปรแกรมนั้น หรือกด Config › httpd.conf เปลี่ยน Listen 80 เป็น 8080 แล้วเปิด http://localhost:8080
MySQL ขึ้น Error: MySQL shutdown unexpectedly
มักเกิดจากมี MySQL อีกตัวติดตั้งในเครื่องแล้วใช้พอร์ต 3306 ให้หยุด Service ตัวนั้นก่อน อย่าลบโฟลเดอร์ data ถ้ายังไม่ได้สำรองข้อมูล
เปิดไฟล์ .php แล้วเห็นโค้ดดิบหรือเบราว์เซอร์ให้ดาวน์โหลด
เปิดไฟล์จากดิสก์ตรง ๆ (file:///) หรือผ่าน Live Server ซึ่งไม่รัน PHP ต้องเปิดผ่าน http://localhost เท่านั้น
2.3

โครงสร้างโฟลเดอร์โครงงาน และ Git

สร้างโฟลเดอร์ my-website ไว้ใน htdocs เพื่อให้ไฟล์ PHP ในบทที่ 7 เปิดผ่าน http://localhost/my-website/ ได้ทันทีโดยไม่ต้องย้ายโฟลเดอร์ แล้วเปิดโฟลเดอร์นี้ใน VS Code (File › Open Folder)

my-website/
├── index.html
├── .gitignore
├── css/
│   └── style.css
├── js/
│   └── main.js
├── images/
│   └── .gitkeep        ← ไฟล์ว่าง ให้ Git เก็บโฟลเดอร์ได้
└── includes/          ← ใช้ในบทที่ 7
    ├── header.php
    └── footer.php

หน้าที่ของแต่ละโฟลเดอร์

  • css/ ไฟล์สไตล์ทั้งหมด
  • js/ ไฟล์ JavaScript
  • images/ รูปภาพ โลโก้ ไอคอน
  • includes/ ส่วนที่ใช้ซ้ำหลายหน้า เช่น header.php, footer.php, db.php เรียกใช้ด้วย require_once
  • .gitignore รายชื่อไฟล์ที่ไม่ให้ Git เก็บ เช่น .env และ wp-config.php

index.html เริ่มต้นที่ใช้ทดสอบทั้ง Live Server และข้อ 2.4 (ลองพิมพ์ ! แล้วกด Tab ใน VS Code เพื่อสร้างโครงหน้าเร็ว ๆ ด้วย Emmet)

โค้ด
<!doctype html>
<html lang="th">
<head>
  <meta charset="utf-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>เว็บไซต์ของฉัน</title>
  <link rel="stylesheet" href="css/style.css">
</head>
<body>
  <h1>Hello World</h1>
  <p id="greeting"></p>
  <script src="js/main.js"></script>
</body>
</html>

2.4

AI Pair Programming Setup

ทางเลือก A: GitHub Copilot ใน VS Code

  1. สมัครบัญชี GitHub นักศึกษาขอสิทธิ์ GitHub Education ด้วยอีเมลมหาวิทยาลัยได้ ซึ่งรวมการใช้ Copilot แบบเต็ม ถ้ายังไม่ได้รับสิทธิ์ ใช้แผน Copilot Free ที่มีโควตาจำกัดต่อเดือนไปก่อน
  2. ติดตั้งส่วนขยาย GitHub Copilot (ผู้พัฒนา GitHub) แล้ว Sign in ด้วยบัญชี GitHub
  3. เมื่อเห็นไอคอน Copilot ที่แถบสถานะด้านล่าง แปลว่าพร้อมใช้

ทางเลือก B: Cursor

  1. ดาวน์โหลดจาก cursor.com ตอนเปิดครั้งแรกนำเข้าส่วนขยายและการตั้งค่าจาก VS Code ได้
  2. เปิดโฟลเดอร์ my-website ตัวเดิม
  3. ใช้ Tab รับคำแนะนำ, Ctrl/Cmd+K สั่งแก้โค้ดตรงตำแหน่ง, Ctrl/Cmd+L เปิดหน้าต่างแชต

ทดลองเขียน Hello World ด้วย AI

  1. เปิด js/main.js ลบโค้ดเดิม แล้วพิมพ์เฉพาะ บรรทัดคอมเมนต์ ที่บอกสิ่งที่ต้องการ
  2. กด Enter รอคำแนะนำตัวอักษรสีจาง (ghost text) แล้วกด Tab เพื่อรับ หรือ Esc เพื่อปฏิเสธ
  3. อ่านทุกบรรทัดก่อนรับ แล้วเปิด index.html ด้วย Live Server ตรวจว่าทำงานจริง

ตัวอย่างโค้ดหลังรับคำแนะนำและตรวจแล้ว บรรทัดแรกคือสิ่งที่นักศึกษาพิมพ์เอง ส่วนที่เหลือมาจาก AI ซึ่งแต่ละครั้งอาจได้ต่างกัน

โค้ด
// แสดงข้อความ Hello World ในย่อหน้า id="greeting" พร้อมวันที่ปัจจุบันแบบภาษาไทย
const greeting = document.getElementById("greeting");
const today = new Date().toLocaleDateString("th-TH", { dateStyle: "long" });
greeting.textContent = `Hello World! วันนี้วันที่ ${today}`;

โค้ด
<!doctype html>
<html lang="th">
<head>
  <meta charset="utf-8">
  <title>Hello World</title>
</head>
<body>
  <h1>Hello World</h1>
  <p id="greeting"></p>
  <script>
    // แสดงข้อความ Hello World ในย่อหน้า id="greeting" พร้อมวันที่ปัจจุบันแบบภาษาไทย

แบบบันทึกผลการทำงาน

หัวข้อตัวอย่างการกรอก
เครื่องมือ / แผนที่ใช้GitHub Copilot (GitHub Education) ใน VS Code
คำสั่ง (Prompt) หรือคอมเมนต์ที่พิมพ์// แสดงข้อความ Hello World ในย่อหน้า id="greeting" พร้อมวันที่ปัจจุบันแบบภาษาไทย
สิ่งที่ AI เสนอโค้ด 3 บรรทัด ใช้ getElementById และ toLocaleDateString
รับทั้งหมด / แก้ไข / ปฏิเสธรับ แต่แก้ innerHTML เป็น textContent เพราะข้อความไม่มีแท็ก HTML
ผลการทดสอบเปิดผ่าน Live Server แสดง "Hello World! วันนี้วันที่ …" ถูกต้อง ไม่มี error ใน Console
อธิบายโค้ดด้วยคำพูดของตนเองบรรทัดที่ 2 หา element ที่มี id greeting, บรรทัดที่ 3 สร้างวันที่ภาษาไทย, บรรทัดที่ 4 ใส่ข้อความลงในย่อหน้า
ข้อตกลงการใช้ AI ในรายวิชา (ตามหัวข้อ 2.21.3): ต้องอธิบายโค้ดที่รับมาได้ทุกบรรทัด ตรวจความปลอดภัยก่อนใช้ และห้ามวางรหัสผ่าน Token หรือข้อมูลส่วนบุคคลลงในหน้าต่างแชตของ AI

  • ตอนที่ AI แสดงคำแนะนำสีจางก่อนกด Tab
