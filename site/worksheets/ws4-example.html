box.html

โค้ด
<!DOCTYPE html>
<html lang="th">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1">
  <title>ทดลอง CSS Selector และ Box Model</title>
  <style>
    /* Element Selector: มีผลกับทุกแท็กชนิดนั้น */
    body {
      font-family: Tahoma, "Leelawadee UI", sans-serif;
      background-color: #f4f6f8;
      color: #222222;
    }
    h1 {
      color: #1f4d3a;
    }

    /* Class Selector: ใช้ซ้ำได้หลายแท็ก */
    .note {
      background-color: #fff7e0;
      color: #6b4a00;
    }

    /* ID Selector: ใช้กับแท็กเดียวในหน้า */
    #intro {
      font-size: 20px;
      font-weight: bold;
    }

    /* Box Model: content + padding + border + margin */
    .box {
      width: 300px;              /* content */
      padding: 20px;             /* ระยะจากขอบถึงเนื้อหา */
      border: 4px solid #1f4d3a; /* เส้นขอบ */
      margin: 24px;              /* ระยะห่างจากกล่องอื่น */
      background-color: #ffffff;
    }
  </style>
</head>
<body>
  <h1>ทดลอง CSS Selector และ Box Model</h1>
  <p id="intro">ย่อหน้านี้ใช้ ID Selector</p>
  <p class="note">ย่อหน้านี้ใช้ Class Selector ชื่อ note</p>

  <div class="box">กล่องที่ 1: เปิด DevTools แล้วดูแผนภาพ Box Model ของกล่องนี้</div>
  <div class="box note">กล่องที่ 2: ใช้ 2 class พร้อมกัน (box และ note)</div>
</body>
</html>
Selectorเขียนอย่างไรมีผลกับ
Elementbody { … } h1 { … }ทุกแท็กชนิดนั้นในหน้า
Class.note { … }ทุกแท็กที่มี class="note" ใช้ซ้ำได้ และแท็กเดียวมีหลาย class ได้
ID#intro { … }แท็กเดียวที่มี id="intro" (id ห้ามซ้ำในหน้า)

ถ้าหลาย Selector ตั้งค่าเดียวกัน ID ชนะ Class และ Class ชนะ Element (Specificity) เพราะฉะนั้นกล่องที่ 2 ได้พื้นสีเหลืองจาก .note แม้ .box ตั้งพื้นสีขาวไว้ก่อน เพราะทั้งสองเป็น Class เท่ากัน ตัวที่เขียนทีหลังจึงชนะ

  1. เปิด box.html ด้วย Live Server คลิกขวาที่กล่องที่ 1 เลือก Inspect (หรือ F12 / Cmd+Opt+I)
  2. เลื่อนเมาส์บนแท็กใน Elements จะเห็นสีทับบนหน้าเว็บ: ฟ้า = content, เขียว = padding, เหลือง = border, ส้ม = margin
  3. เปิดแท็บ Computed ด้านขวา จะเห็นแผนภาพเหมือนรูปซ้าย
  4. ในแท็บ Styles คลิกที่ตัวเลขเพื่อแก้ค่าได้ทันที (กดลูกศรขึ้นลงเพื่อเพิ่มลดทีละ 1) แล้วบันทึกผลตามตารางด้านล่าง

border: 10px solid300 + 40 + 20 = 360pxขอบหนาขึ้นก็ทำให้กล่องกว้างขึ้น

ข้อผิดพลาดที่พบบ่อย
ฟอนต์ไม่เปลี่ยน
ตรวจว่าชื่อใน font-family สะกดตรงกับ Google Fonts รวมตัวพิมพ์ใหญ่และเครื่องหมายคำพูด และแท็ก link ของ Google Fonts อยู่ก่อน style.css ดูได้ใน DevTools แท็บ Network กรองคำว่า font
ตัวหนาดูแปลกหรือไม่หนาจริง
โหลดน้ำหนักที่ใช้ไม่ครบ เบราว์เซอร์จึงทำตัวหนาเทียมขึ้นมาเอง ให้เพิ่มน้ำหนัก 700 ใน URL ของ Google Fonts
var() ไม่ทำงาน
ตัวแปรต้องขึ้นต้นด้วย -- สองขีด และชื่อตัวพิมพ์ใหญ่เล็กต้องตรงกัน --Color-Primary กับ --color-primary คือคนละตัว

4.3

รายการสินค้าด้วย CSS Grid

repeat(auto-fit, minmax(250px, 1fr)) แปลว่า "ใส่คอลัมน์ให้ได้มากที่สุดโดยแต่ละคอลัมน์กว้างอย่างน้อย 250px แล้วแบ่งพื้นที่ที่เหลือให้เท่ากัน" จำนวนคอลัมน์จึงเปลี่ยนเองตามความกว้างจอ ไม่ต้องเขียน Media Query
