คลาสความหมายกล่องต่อแถว
col-12ทุกขนาดจอ กว้าง 12 จาก 12 ส่วน1 (มือถือ)
col-md-6ตั้งแต่ 768px ขึ้นไป กว้าง 6 ส่วน2 (แท็บเล็ต)
col-lg-4ตั้งแต่ 992px ขึ้นไป กว้าง 4 ส่วน3 (คอมพิวเตอร์)
colแบ่งพื้นที่เท่ากันอัตโนมัติตามจำนวนคอลัมน์ในแถวเท่าจำนวน col
g-3ช่องว่างระหว่างคอลัมน์และแถว (gutter) ระดับ 3-

จุดตัดของ Bootstrap 5: sm 576px · md 768px · lg 992px · xl 1200px · xxl 1400px คลาสที่มีขนาดกำกับจะมีผลตั้งแต่ขนาดนั้นขึ้นไป (Mobile-first) เหมือน @media (min-width) ในใบงานที่ 4

ข้อผิดพลาดที่พบบ่อย
คอลัมน์ไม่เรียงข้างกัน
ลูกโดยตรงของ .row ต้องเป็น .col-* และ .row ต้องอยู่ใน .container หรือ .container-fluid
ตัวเลขในแถวรวมเกิน 12
ส่วนที่เกินจะขึ้นแถวใหม่เอง ถ้าตั้งใจให้อยู่แถวเดียว ต้องรวมได้ไม่เกิน 12
ใส่ padding หรือ border ที่ div.col ตรง ๆ แล้วระยะเพี้ยน
ใส่สไตล์ที่ div ด้านในคอลัมน์แทน เหมือนกล่อง .demo ในตัวอย่าง

  1. novalidate ที่ form ปิดกล่องเตือนของเบราว์เซอร์ เพื่อให้ Bootstrap แสดงข้อความใต้ช่องแทน
  2. เมื่อกดส่ง สคริปต์เรียก form.checkValidity() ซึ่งตรวจ required, minlength, type="email" และ pattern ตามที่เขียนใน HTML
  3. เติมคลาส was-validated ที่ form แล้ว Bootstrap จะใส่กรอบสีเขียวหรือแดง และแสดง valid-feedback หรือ invalid-feedback ที่อยู่ถัดจากช่องนั้น
  4. เรื่องที่ HTML ตรวจเองไม่ได้ เช่น รหัสผ่านสองช่องตรงกันไหม ใช้ setCustomValidity() ถ้าส่งข้อความที่ไม่ว่างจะถือว่าช่องนั้นไม่ผ่าน ส่งข้อความว่างคือผ่าน

/*
  theme.css ธีมไร่ภูคำ ปรับทับ Bootstrap 5.3.8 โดยไม่แก้ไฟล์ของ Bootstrap
  ต้องโหลดไฟล์นี้หลัง bootstrap.min.css เสมอ
  ฟอนต์ Sarabun (Cadson Demak) จาก Google Fonts ใบอนุญาต SIL Open Font License 1.1
*/

/* 1) ตัวแปรระดับหน้า: มีผลกับ .text-primary .bg-primary ลิงก์ ฟอนต์ และขอบมน */
:root {
  --bs-primary: #1f4d3a;
  --bs-primary-rgb: 31, 77, 58;       /* .bg-primary และ .text-primary ใช้ค่านี้ */
  --bs-link-color: #1f4d3a;

  --bs-link-hover-color: #173a2c;

body {
  background-color: #f3ede3;
}

/* 2) ปุ่ม: .btn-primary กำหนดสีของตัวเอง ไม่ได้อ่านจาก --bs-primary ต้องตั้งแยก */

.navbar-dark {

  --bs-navbar-hover-color: #ffffff;
}

/* 5) กรอบเรืองแสงตอนคลิกช่องกรอก */
