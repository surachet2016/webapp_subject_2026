# ใบงานปฏิบัติการที่ 3: การสร้างโครงสร้างหน้าเว็บด้วย HTML5 Semantic Elements และแบบฟอร์มตรวจสอบข้อมูล

**ผลการเรียนรู้ที่คาดหวัง (CLO):** CLO 3 (พัฒนาโครงสร้างเว็บด้วย HTML ได้ตามข้อกำหนด) และ CLO 5 (ประยุกต์ความรู้สร้างหน้าเว็บแก้ปัญหาตามโจทย์)

**เครื่องมือและซอฟต์แวร์ที่ใช้:** Visual Studio Code, Live Server, Chrome DevTools

## คำสั่งและขั้นตอนการปฏิบัติงาน

**การแบ่งส่วนของใบงาน (ตรงกับแผนการสอนรายสัปดาห์ใน มคอ.3):** ส่วนที่ 1 สัปดาห์ที่ 3 ทำข้อ 3.0; ส่วนที่ 2 สัปดาห์ที่ 4 ทำข้อ 3.1–3.4 ส่งใบงานฉบับสมบูรณ์ทั้งสองส่วนผ่าน Google Classroom ภายในสัปดาห์ที่ 4 และประเมินด้วยแบบประเมินรูบริกฉบับเดียว

- **3.0 โครงสร้างเอกสาร HTML5 พื้นฐาน (ส่วนที่ 1)**: สร้างหน้าแนะนำตนเองหรือแนะนำรายวิชา โดยกำหนด <!DOCTYPE html>, lang และ charset UTF-8, หัวเรื่อง <h1>–<h6>, ย่อหน้า, รายการ <ul>/<ol>, ลิงก์ <a> และรูปภาพ <img> พร้อม alt โดยอ้างเส้นทางไฟล์แบบสัมพัทธ์
- **3.1 การสร้างโครงสร้างเชิงความหมาย (Semantic Layout)**: เขียนเอกสาร HTML5 โดยใช้แท็ก <header>, <nav>, <main>, <article>, <section>, <aside>, และ <footer> สำหรับหน้าข่าวสารหรือบทความ
- **3.2 การสร้างตารางข้อมูล (Table)**: สร้างตารางแสดงตารางเรียนหรือตารางราคาสินค้า พร้อมใช้งานแท็ก <caption>, <thead>, <tbody>, <th>, และ <td> อย่างถูกต้องตามมาตรฐาน W3C
- **3.3 การสร้างแบบฟอร์มสมัครงาน (Interactive Form)**: สร้างแบบฟอร์มรับข้อมูลที่ประกอบด้วย Text, Password, Email, Tel, Radio, Checkbox, Select Dropdown, Textarea และปุ่ม Submit พร้อมกำหนด Attribute required และ pattern (Regex)
- **3.4 AI-Assisted Accessibility Audit**: ใช้ AI ตรวจสอบโค้ด HTML ว่ามีจุดบกพร่องตามมาตรฐาน WCAG หรือไม่ (เช่น ขาด alt บนรูปภาพ หรือขาด label บนฟอร์ม) พร้อมแก้ไขให้ผ่านการประเมิน

**การแปลงคะแนน:** คะแนนจากแบบประเมินรูบริก (เต็ม 20) ÷ 20 = คะแนนเก็บของใบงานนี้ (เต็ม 1 คะแนน) ใบงาน 10 ชุดรวมเป็น 10 คะแนนตาม มคอ.3

**เกณฑ์การส่งมอบงานและการประเมินผล:** บันทึกภาพหน้าจอผลลัพธ์การทำงานพร้อมแนบซอร์สโค้ด และส่งผ่านระบบบริหารการเรียนรู้ (LMS) ภายในระยะเวลาที่กำหนด โดยจะประเมินผลตามเกณฑ์รูบริกการประเมินใบงาน
