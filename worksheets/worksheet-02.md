# ใบงานปฏิบัติการที่ 2: การติดตั้งและจัดเตรียมสภาพแวดล้อมการพัฒนาเว็บ และการประยุกต์ใช้ AI Coding Assistants

**ผลการเรียนรู้ที่คาดหวัง (CLO):** CLO 1 (อธิบายโครงสร้างและหลักการทำงานของเว็บ), CLO 3 (ใช้เครื่องมือพัฒนาและเผยแพร่เว็บไซต์ได้) และ CLO 6 (อ้างอิงแหล่งที่มาและเคารพสิทธิการใช้งาน)

**เครื่องมือและซอฟต์แวร์ที่ใช้:** Visual Studio Code, Git, เว็บเบราว์เซอร์ Google Chrome, ส่วนขยาย VS Code (Live Server, Prettier, GitHub Copilot)

## คำสั่งและขั้นตอนการปฏิบัติงาน

- **2.1 การติดตั้งและปรับแต่ง VS Code**: ติดตั้งโปรแกรม Visual Studio Code พร้อมติดตั้งส่วนขยายที่จำเป็นสำหรับการพัฒนาเว็บ ได้แก่ Live Server, Prettier - Code Formatter และ Auto Rename Tag (ดูหัวข้อ 2.20.1 ในบทที่ 2)
- **2.2 การติดตั้งสภาพแวดล้อมจำลอง (XAMPP)**: ติดตั้ง XAMPP (Windows) หรือทางเลือกบน macOS ตามภาคผนวก ค และทดสอบเปิดใช้งานบริการ Apache และ MySQL พร้อมตรวจสอบหน้า Dashboard บน http://localhost
- **2.3 การสร้างโครงสร้างโฟลเดอร์โครงงาน (Project Directory)**: สร้างโฟลเดอร์สำหรับพัฒนาเว็บไซต์ แบ่งหมวดหมู่ไฟล์อย่างเป็นระเบียบ ได้แก่ /css, /js, /images และ /includes (ดูหัวข้อ 2.20.1 ในบทที่ 2 โฟลเดอร์ /includes ใช้กับไฟล์ PHP ในบทที่ 7) แล้วฝึกสร้าง Repository ด้วย git init และบันทึกด้วย git commit ตามหัวข้อ 2.20.2
- **2.4 AI Pair Programming Setup**: ทดลองติดตั้งและเปิดใช้งานผู้ช่วย AI เช่น GitHub Copilot หรือทดลองใช้ Cursor เขียนคำสั่งทักทาย 'Hello World' และบันทึกผลการทำงาน

**การแปลงคะแนน:** คะแนนถ่วงน้ำหนักจากแบบประเมินรูบริก (เต็ม 20) ÷ 20 = คะแนนเก็บของใบงานนี้ (เต็ม 1 คะแนน) ใบงาน 10 ชุดรวมเป็น 10 คะแนนตาม มคอ.3

**เกณฑ์การส่งมอบงานและการประเมินผล:** บันทึกภาพหน้าจอผลลัพธ์การทำงานพร้อมแนบซอร์สโค้ด และส่งผ่านระบบบริหารการเรียนรู้ (LMS) ภายในระยะเวลาที่กำหนด โดยจะประเมินผลตามเกณฑ์รูบริกการประเมินใบงาน
