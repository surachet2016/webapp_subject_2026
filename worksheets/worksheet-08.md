# ใบงานปฏิบัติการที่ 8: การเชื่อมต่อฐานข้อมูล MySQLi, การพัฒนาระบบ CRUD และการป้องกัน SQL Injection

**ผลการเรียนรู้ที่คาดหวัง (CLO/ELO):** CLO 3 (พัฒนาระบบฐานข้อมูลเชิงสัมพันธ์) และ CLO 4 (ความมั่นคงปลอดภัยของข้อมูล)

**เครื่องมือและซอฟต์แวร์ที่ใช้:** phpMyAdmin, MySQL, PHP 8, VS Code

## คำสั่งและขั้นตอนการปฏิบัติงาน

- **8.1 การออกแบบและสร้างฐานข้อมูลเชิงสัมพันธ์**: สร้างฐานข้อมูลร้านค้าและตารางข้อมูล (เช่น members, products) พร้อมกำหนด Primary Key, Foreign Key และ Data Types ใน phpMyAdmin (ดูหัวข้อ 8.1.1)
- **8.2 การพัฒนาระบบจัดการข้อมูลครบวงจร (CRUD)**: เขียนโปรแกรมภาษา PHP เชื่อมต่อ MySQLi (ผู้ใช้ MAMP ต้องใช้รหัสผ่านของ root ตามภาคผนวก ค) เพื่อทำระบบแสดงรายการข้อมูล, เพิ่มข้อมูลใหม่, แก้ไขข้อมูลเดิม, และลบข้อมูลพร้อมหน้าต่างยืนยัน
- **8.3 การป้องกัน SQL Injection ด้วย Prepared Statements**: ปรับปรุงคำสั่งค้นหาข้อมูลและระบบล็อกอินทั้งหมดให้ใช้ mysqli_prepare(), bind_param(), และ execute() 100%
- **8.4 การอัปโหลดไฟล์รูปภาพและการแบ่งหน้า (Pagination)**: พัฒนาระบบอัปโหลดรูปภาพสินค้าไปเก็บในโฟลเดอร์เซิร์ฟเวอร์และบันทึกชื่อไฟล์ลงฐานข้อมูล พร้อมทำระบบแบ่งหน้าแสดงผลข้อมูล (LIMIT/OFFSET)

**เกณฑ์การส่งมอบงานและการประเมินผล:** บันทึกภาพหน้าจอผลลัพธ์การทำงานพร้อมแนบซอร์สโค้ด และส่งผ่านระบบบริหารการเรียนรู้ (LMS) ภายในระยะเวลาที่กำหนด โดยจะประเมินผลตามเกณฑ์รูบริกการประเมินใบงาน
