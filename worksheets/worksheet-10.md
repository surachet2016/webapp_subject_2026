# ใบงานปฏิบัติการที่ 10: การจัดตั้งเว็บไซต์บนเซิร์ฟเวอร์จริง, การติดตั้ง HTTPS และการตรวจสอบประสิทธิภาพ

**ผลการเรียนรู้ที่คาดหวัง (CLO/ELO):** CLO 3 (นำส่งและบริหารจัดการเว็บไซต์) และ CLO 4 (การประเมินคุณภาพและประสิทธิภาพระบบ)

**เครื่องมือและซอฟต์แวร์ที่ใช้:** บริการ Web Hosting/Cloud, โปรแกรม FileZilla (SFTP), Google Chrome Lighthouse

## คำสั่งและขั้นตอนการปฏิบัติงาน

- **10.1 การวางแผนจดทะเบียนโดเมนเนมและการตั้งค่า DNS**: ศึกษาการเลือกชื่อโดเมน และฝึกปฏิบัติการกำหนดระเบียน DNS (A Record, CNAME) ชี้ไปยังโฮสติ้งเซิร์ฟเวอร์
- **10.2 การอัปโหลดเว็บไซต์และฐานข้อมูลขึ้นสู่ Server จริง**: ส่งไฟล์โครงงานเว็บไซต์ขึ้นสู่เซิร์ฟเวอร์ผ่านโปรแกรม FileZilla (SFTP) และนำเข้าไฟล์ฐานข้อมูล (.sql) ใน phpMyAdmin บนโฮสติ้งจริง (ดูหัวข้อ 10.3.1 ส่วนเว็บแบบสถิตล้วนเผยแพร่ด้วย GitHub Pages ได้ตามหัวข้อ 10.3.2)
- **10.3 การเปิดใช้งานใบรับรองความปลอดภัย HTTPS (SSL/TLS)**: ตรวจสอบการติดตั้งใบรับรองความปลอดภัยฟรีด้วย Let's Encrypt / Cloudflare และทดสอบการเรียกใช้งานผ่าน https://
- **10.4 การตรวจสอบประสิทธิภาพด้วย Google Lighthouse**: รันการทดสอบ Performance, Accessibility, Best Practices, และ SEO พร้อมนำผลลัพธ์มาวิเคราะห์และปรับปรุงให้ได้คะแนนระดับดี (สีเขียว)

**เกณฑ์การส่งมอบงานและการประเมินผล:** บันทึกภาพหน้าจอผลลัพธ์การทำงานพร้อมแนบซอร์สโค้ด และส่งผ่านระบบบริหารการเรียนรู้ (LMS) ภายในระยะเวลาที่กำหนด โดยจะประเมินผลตามเกณฑ์รูบริกการประเมินใบงาน
