# ใบงานปฏิบัติการที่ 5: การพัฒนาส่วนติดต่อผู้ใช้แบบ Responsive ด้วย Bootstrap 5 และ Utility Classes

**ผลการเรียนรู้ที่คาดหวัง (CLO/ELO):** CLO 3 (สร้างสรรค์ส่วนต่อประสานผู้ใช้ด้วยเฟรมเวิร์กมาตรฐาน)

**เครื่องมือและซอฟต์แวร์ที่ใช้:** Visual Studio Code, Bootstrap 5 (CDN), Chrome Mobile Simulator

## คำสั่งและขั้นตอนการปฏิบัติงาน

- **5.1 การติดตั้งและใช้งาน Bootstrap 5 Grid System**: สร้างหน้าเว็บโดยใช้โครงสร้าง .container, .row, และการแบ่งคอลัมน์ตามขนาดหน้าจอ เช่น .col-12 .col-md-6 .col-lg-4
- **5.2 การประกอบคอมโพเนนต์หลัก**: สร้างหน้า Landing Page ที่มี Navbar ยุบขยายได้, Hero Banner, การ์ดสินค้า (.card จัดเรียงด้วย .row และ .col-*) และ Modal (ดูหัวข้อ 5.8.5 Bootstrap 5 ไม่มี .card-deck แล้ว) สำหรับป็อปอัปแสดงรายละเอียด
- **5.3 การสร้างและตรวจสอบความถูกต้องของฟอร์ม (Form Validation)**: สร้างฟอร์มลงทะเบียนด้วยคลาส .form-control พร้อมเขียนสคริปต์สั้นเปิดใช้งานคลาส .was-validated, .valid-feedback, และ .invalid-feedback
- **5.4 AI-Assisted Component Generation**: ใช้ AI ช่วยร่างโครงสร้างโค้ดหน้า Dashboard ด้วย Bootstrap 5 และปรับแต่งสีสันให้ตรงตามธีมที่กำหนด

**เกณฑ์การส่งมอบงานและการประเมินผล:** บันทึกภาพหน้าจอผลลัพธ์การทำงานพร้อมแนบซอร์สโค้ด และส่งผ่านระบบบริหารการเรียนรู้ (LMS) ภายในระยะเวลาที่กำหนด โดยจะประเมินผลตามเกณฑ์รูบริกการประเมินใบงาน
